Live2D Cubism：從拆圖到髮絲擺動

目標不是先做完整 VTuber 模型，而是把拆好的角色做成適合 Wallpaper Engine 的低幅度動態桌布。先用「頭髮左右輕擺」理解 Live2D 最核心的模型結構，再往呼吸、衣服與物理效果延伸。

IMAGE → MOTION

先理解變形鏈，再開始做動畫

Live2D 的重點不是把一張圖直接變成動畫，而是先把 PSD 圖層轉成可變形的 ArtMesh，再用 Deformer 與 Parameter 記錄不同 Keyform，最後才讓 Physics 或其他輸入驅動它。

參考影片

01

Live2D 的核心流程

PSD 圖層
→ ArtMesh
→ Deformer
→ Parameter / Keyform
→ Physics / Animation
→ Wallpaper Engine
PSD 圖層
素材來源。頭髮、臉、手、衣服等需要依預期動作拆成可獨立處理的部件。
ArtMesh
貼在圖像上的可變形網格。沒有合理的 Mesh，就沒有穩定的局部變形。
Deformer
用較高層級的控制框去帶動一個或多個 ArtMesh。柔軟形變通常先使用 Warp Deformer。
Parameter
描述一個可變化的數值，例如「髮擺動 X」。不同參數值可以保存不同 Keyform。
Physics
後續讓頭髮或衣服產生延遲與慣性，不需要一開始就碰。
目標範圍Wallpaper Engine 桌布優先做「自然的小動作」，不需要先把完整 VTuber 臉部追蹤系統搬進來。
02

先讓部件成為可控制的 ArtMesh

從單一部件開始，例如「髮」。選到實際的 ArtMesh 後產生自動 Mesh，先使用標準設定，再依變形需求調整。

頭髮
需要彎曲，Mesh 可以使用中等到較細的密度。
衣服 / 手 / 臉
通常使用中等密度，再依實際變形程度修正。
椅子等硬物
若幾乎不變形，不需要為了「看起來專業」塞大量頂點。
Mesh 越細不等於越好

網格密度要服務變形需求。過度細分只會增加編輯負擔與資料量，並不會自動讓動畫更自然。

03

用 Warp Deformer 控制頭髮

建立例如「髮_擺動」的 Warp Deformer，讓頭髮 ArtMesh 成為它的子物件。之後做大範圍柔軟形變時，優先調整 Deformer，而不是直接把 ArtMesh 頂點一個個拖爛。

三種「點」不要混參數上的 Keyform、Warp Deformer 的控制點、ArtMesh 的頂點是不同層級的東西。
  • 01
    選取「髮_擺動」Warp Deformer

    確認目前選到的是 Deformer，不是資料夾或底下的 ArtMesh。

  • 02
    讓框主要覆蓋需要變形的頭髮

    不要為了省事把臉、耳朵與大量衣服一起包進去，否則頭髮一晃，其他部件也會被牽連。

  • 03
    動控制框，不是整顆平移

    Warp Deformer 的價值是讓形變有漸變，而不是把頭髮當成一張貼紙左右搬動。

04

「髮擺動 X」參數與三個 Keyform

建立一個例如 髮擺動 X 的參數，範圍先用 -1 / 0 / +1。每個位置建立 Keyform，保存同一個 Warp Deformer 在不同狀態下的形狀。

髮擺動 X
-1 -------- 0 -------- +1
左           中          右
  1. 01
    0：建立原始 Keyform

    保持原本頭髮形狀，作為中立狀態。

  2. 02
    +1：建立右擺 Keyform

    新增關鍵點後，調整「髮_擺動」Warp Deformer，使髮絲輕微往右彎。

  3. 03
    -1：建立左擺 Keyform

    新增關鍵點後，往相反方向調整。

  4. 04
    來回拖參數檢查插值

    確認 -1 → 0 → +1 能平滑變化，而且 0 仍回到原始狀態。

自然的髮擺動不是整片平移

頭頂與髮根最接近固定點，應該動得最少；中段稍微移動；髮尾與側髮可以移得更多。桌布的幅度應該小到不搶注意力，卻能讓畫面長時間觀看時仍有生命感。

05

變形後露出透明，不是在 Cubism 裡「補顏色」

如果髮絲一拉就露出透明，問題通常不是 Cubism 缺少畫筆，而是原始素材沒有畫出「原本被遮住、但動起來可能露出」的內容。

邊界被拉出去
原圖層畫得太貼邊，需要回 PSD 把頭髮或衣服向外延伸，留下足夠出血。
前景移開後露空
例如瀏海移開後沒有額頭、側髮後沒有臉側或脖子。需要補的是後方結構，而不是隨便填一塊近似顏色。
補片
必要時可以在 PSD 新增額頭、後髮、衣領內側等補片，但新增圖層也代表 Cubism 端要重新確認 Mesh、層級與 Deformer。
核心觀念Live2D 素材需要畫出「靜態圖看不到、動畫時可能看得到」的區域，並讓相鄰部件保持適度重疊。
06

PSD 改完後，Cubism 不要當成會永遠即時同步

Photoshop 是素材來源，Cubism 是建模端。修改 PSD 後先儲存，再回 Cubism 讓素材重新讀取或更新；不要把兩者理解成永久即時連線。

最安全的修改
在原本已對應的圖層上補像素內容，例如延伸髮尾、補額頭或補邊界。
較高風險的修改
改圖層名稱、刪圖層、合併圖層、改群組層級或大量新增圖層，可能讓既有 ArtMesh、Deformer 與參數對應需要重新整理。
Mesh 仍需檢查
即使新像素已經更新進來，原本的 Mesh 分布也不一定自動變得合理；補大的區域後仍要確認 ArtMesh 是否涵蓋並適合變形。
Cubism 找出露空位置
→ 回 PSD 原圖層補畫
→ 儲存 PSD
→ 回 Cubism 更新 / 重新讀取素材
→ 檢查 Mesh、Deformer 與參數是否正常
07

目前素材能做什麼，以及先不要做什麼

如果臉目前仍是一整片，而沒有把左右眼、瞳孔、睫毛、嘴與臉皮進一步拆開，就不適合直接要求完整眨眼、視線追蹤或嘴型。

但對 Wallpaper Engine 來說並不是問題。先完成頭髮微飄、身體呼吸、衣服延遲、手臂極小幅移動與整體重心晃動，已經足以讓靜態桌布自然很多。

下一階段先把髮擺動做乾淨，再加入 Physics；不要同時開五個系統，最後只知道「它在動」，卻不知道是誰把誰弄歪。
