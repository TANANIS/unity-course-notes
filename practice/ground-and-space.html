建立基礎空間與地板

開啟空白 Unity 專案後，第一個很實際的需求是：如果要放入角色，角色至少要有一個可以站立的地面。從這個問題出發，開始整理 Unity 中建立地板與場景空間的幾種方式。

FROM NEED TO TOOL

不是先選工具，而是先確認要解決什麼問題

Plane、Cube、ProBuilder、Terrain 與 Modular Assets 並不是誰比較高級，而是適合不同階段、尺度與場景需求。這次的需求很單純：先建立一塊能讓角色站立、能測試移動與碰撞的地面。

01

問題是怎麼出現的？

這次不是因為課程要求建立 Plane，而是在空白專案中準備放入角色時，自然遇到了「角色要站在哪裡？」這個問題。

思考路徑想建立角色 → 角色需要碰撞與支撐 → 需要地面 → 開始研究 Unity 如何建立空間。

因此這篇筆記的重點不是背誦「地板要用 Plane」，而是建立一個判斷框架：不同場景與開發階段，應該選擇不同的空間建立方式。

02

常見的空間與地板建立方式

Plane
最快建立平坦地面的方式。適合測試地面、簡單平坦區域與 Prototype。
Cube
具有體積，可以壓成薄樓板，也能直接拿來做牆、平台與室內 Greybox。
ProBuilder
Unity 官方的關卡 Blockout / 簡易建模工具，適合直接在 Editor 中拉出較複雜的房間與關卡形狀。
Terrain
Unity 的地形系統，適合山丘、草原、坡地等大型自然環境，而不是一般室內地板。
Modular Assets
以固定規格的地板、牆壁、門框等模型模組進行拼接，常用於正式的室內、地城或城鎮關卡。

03

目前先使用 Plane

現在只需要一塊能讓角色站立、可以測試移動與碰撞的平坦地面，因此 Plane 已經足夠。

Hierarchy
→ 3D Object
→ Plane
尺寸
Unity 預設 Plane 約為 10 × 10 Unity units。一般 3D 專案中常把 1 Unity unit 當作約 1 公尺來建立尺度感。
厚度
Plane 是平面 Mesh，沒有像 Cube 一樣的實際厚度。
碰撞
預設建立的 Plane 會帶有 Mesh Collider，因此可以直接作為角色站立與碰撞測試的地面。
放大
可以透過 Transform Scale 快速擴大測試區域。
Plane 放大後，貼圖發生什麼事？

Transform Scale 不會重新修改 Mesh 的 UV；真正發生的是同一組 UV 被鋪在更大的世界面積上，因此紋理視覺上會變大。正式材質可以再透過 Material Tiling 等方式調整重複密度。

04

Prototype / Greybox 階段先解決玩法問題

現在沒有必要先決定正式遊戲最後要用 Terrain、Blender 模型還是模組化場景。Prototype 階段更重要的是先快速建立可以測試的空間。

  • 01
    角色能站嗎？

    先確認 Collider、重力與角色控制正常。

  • 02
    移動空間合理嗎？

    測試移動速度、轉向、跳躍以及 Camera 距離。

  • 03
    空間比例合理嗎？

    角色與房間、牆壁、平台之間的尺度，需要實際操作才能感覺出來。

  • 04
    再決定正式製作方式

    玩法與尺度確認後，再考慮 ProBuilder、Terrain 或正式 Modular Assets。

核心觀念Prototype 的地板首先是測試工具，不是最終美術資產。
05

接下來可以怎麼練？

先從最小可玩的空間開始，不需要一次把場景做成建築設計作業。

  1. 01
    建立 Plane

    作為第一塊角色可以站立的地面。

  2. 02
    放入簡單角色

    確認角色與地面的碰撞關係。

  3. 03
    加入 Cube

    做牆壁、平台或障礙物，開始感受場景尺度。

  4. 04
    再比較 Plane 與 Cube

    實際操作後理解「平面測試地面」和「有體積的場景結構」差在哪裡。
