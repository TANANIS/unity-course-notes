ch1_8 建立 Script

建立 C# Script Asset，將它掛到 GameObject 上成為 Component，並比較 Project 與 Add Component 兩種建立方式。

SCRIPT ASSET / COMPONENT

腳本檔存在，不代表它已經在場景中執行

Script 先是 Project 裡的 Asset；掛載到 GameObject 後，才會成為該物件的 Component。直接按 Play 卻沒有任何反應，通常只是因為腳本還孤零零地躺在 Assets 裡。

01Project 建立Scripts 資料夾與 C# Script 02掛載腳本拖入 Inspector 03Add Component直接建立並掛載 04兩種方式整理與速度的取捨
01

方法一：在 Project 建立 C# Script

  1. 01
    建立 Scripts 資料夾

    在 Project 視窗的 Assets 空白處按右鍵，選擇 Create → Folder，命名為 Scripts。

  2. 02
    建立 C# Script

    進入 Scripts 資料夾，在空白處按右鍵，選擇 Create → C# Script。

  3. 03
    立即正確命名

    例如 TestOne。課程特別提醒命名要正確，避免之後再修改時增加麻煩。

  4. 04
    雙擊開啟程式碼編輯器

    老師示範撰寫旋轉程式，但本堂重點是建立與掛載流程，程式語法會在後續章節說明。

字幕不足以還原完整程式碼

字幕可辨認老師使用了旋轉相關程式，可能涉及 transform.Rotate 與 Y 軸，但無法可靠還原完整參數與寫法，因此本頁不把猜測偽裝成原始程式碼。

02

把 Script 掛到 GameObject

只在 Project 建立 Script，按 Play 不會讓任何場景物件自動執行它。必須先把腳本附加到目標 GameObject。

  1. 01
    選取 GameObject

    在 Hierarchy 或 Scene 選取要控制的 Cube。

  2. 02
    找到 Script Asset

    在 Project 的 Scripts 資料夾選取剛建立的 C# Script。

  3. 03
    拖到 Inspector

    把 Script 拖進該 GameObject 的 Inspector。掛載成功後，Inspector 會出現腳本 Component。

  4. 04
    按 Play 測試

    老師示範掛載後物件開始旋轉，用來確認腳本確實有執行。

核心關係Project 裡是 Script Asset；掛到 GameObject 後是 Script Component。
03

方法二：從 Add Component 建立新腳本

  1. 01
    選取 GameObject

    先選取要附加腳本的物件。

  2. 02
    開啟 Add Component

    在 Inspector 底部點選 Add Component。

  3. 03
    建立 New Script

    從選單建立新腳本並輸入名稱。建立完成後，腳本會直接掛到目前 GameObject。

  4. 04
    整理檔案位置

    這種方式建立的 Script 可能不在預先規劃的 Scripts 資料夾，需要回到 Project 手動移動整理。

版本介面可能不同

字幕顯示老師使用 Add Component → New Script。不同 Unity 版本的入口名稱或是否直接提供 New Script 可能不同；本頁保留課程操作，不把介面差異偷偷改寫成另一套流程。

04

兩種建立方式的差異

Project → Create → C# Script
可直接指定腳本所在資料夾，專案結構較整齊；建立後還要手動掛到 GameObject。
Add Component → New Script
建立後立即掛到目前 GameObject，操作較快；之後可能還要移動 Script Asset 整理資料夾。
刪除資料夾或腳本
可在 Project 右鍵選擇 Delete，但刪除 Asset 會影響所有引用它的物件，不能把它當普通場景物件隨意處理。
選擇原則重視專案結構，用 Project 建立；臨時快速掛載，可從 Add Component 建立後再整理。
