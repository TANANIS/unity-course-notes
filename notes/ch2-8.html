ch2_8 方法

方法（Method）可以把一段工作包成可重複呼叫的程式區塊。這堂重點是理解方法名稱、參數、回傳值，以及呼叫方法時資料如何進出。

METHOD

把一段工作取名字，之後再呼叫它

方法可以把較長的程式拆成有意義的小區塊，提升可讀性與重複利用。方法不會因為「寫好了」就自動執行，還需要被呼叫。

01

方法的基本結構

void Jump()
{
    Debug.Log("跳跳跳");
}
void
表示這個方法沒有回傳值。
Jump
方法名稱，用來描述這段程式負責做什麼。
()
參數列表；空的小括號代表這個方法目前不需要傳入資料。
{ ... }
方法實際執行的內容。
方法放在哪裡？

課堂提醒：方法要宣告在 class 裡，但不會再宣告在另一個方法裡。像 Start() 與自訂的 Jump() 都是同一層級的方法。

02

方法要被呼叫才會執行

void Start()
{
    Jump();
}

void Jump()
{
    Debug.Log("跳跳跳");
}

只宣告 Jump() 並不會自己發生事情。必須在 Start() 或其他地方使用 Jump(); 呼叫它。

一句話記憶宣告方法是在定義「可以做什麼」；呼叫方法才是真的「去做」。
03

有回傳值的方法

private float _hp = 100f;

float GetHP()
{
    return _hp;
}

如果方法需要把資料送回呼叫端，就不能使用 void，而要宣告實際回傳的型別。

float myHp = GetHP();
float
這裡表示 GetHP() 會回傳一個浮點數。
return
把值傳回呼叫端，並離開目前方法。
float myHp = GetHP();
用同樣能承接回傳值的型別接住結果。
return 之後

課堂提醒，執行到 return 後就會離開方法，因此同一路徑上寫在它後面的程式不會再被執行。

04

方法也可以接收參數

private float _hp = 100f;

void SetHP(float hp)
{
    _hp = hp;
}

參數讓呼叫端可以把資料交給方法。呼叫時：

SetHP(65f);

方法裡的 hp 就會收到 65f，再把它指定給欄位 _hp。

「有參數」和「有回傳值」是兩件獨立的事情。方法可以沒有參數、有參數、沒有回傳值，或同時有參數和回傳值。

05

參數和欄位同名時，可以使用 this

老師示範如果欄位與參數都叫 hp：

private float hp = 100f;

void SetHP(float hp)
{
    hp = hp;
}

這樣左右兩邊都指向方法參數，並沒有修改物件本身的欄位。

如果真的要同名，可以明確寫：

void SetHP(float hp)
{
    this.hp = hp;
}
this.hp
代表目前這個物件自己的 hp 欄位。
hp
在這個方法裡優先指向參數 hp。

課堂也用底線命名欄位（例如 _hp）來避免名稱混淆。

06

Unity Inspector 欄位的課堂補充

老師在示範 HP 時順帶提醒：如果欄位是 public 且 Script 已掛在 GameObject 上，Inspector 中可能已經保存了一個值，因此執行時看到的值可能不是你剛在程式碼裡修改的預設值。

public float hp = 500f;

如果 Inspector 先前已經把它設成 20，課堂示範中 Unity 仍會使用 Inspector 保存的 20。這也是老師遇到「明明程式寫 500，執行卻不是 500」的原因。

[HideInInspector]
public float hp;

private float _hp;
[HideInInspector]
老師用它示範把欄位從 Inspector 隱藏；隱藏不代表原本保存的值自動消失。
private
老師接著把示範欄位改成 private，使它不再直接出現在一般 Inspector 欄位中。
這是順帶補充

這段主要是在提醒 Unity Inspector 可能影響欄位看到的值；public、private、序列化與物件欄位本身，老師表示後面的類別與物件章節還會再談。

本堂結論方法把工作包成可呼叫的區塊；參數把資料送進去，return 把結果送回來。
