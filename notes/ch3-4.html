ch3_4 Vector_2（向量類介紹）

上一堂在看「一個向量自己的方向與長度」，這堂開始比較兩個向量。老師用兩個 Cube 示範 Vector3.Dot 與 Vector3.Cross，分別判斷目標位於物件的前後與左右。

DOT · CROSS · RELATIVE DIRECTION

Dot 問前後，Cross 問左右

先準備兩支箭：一支是「我朝哪裡」，另一支是「目標在哪個方向」。再讓 Dot 或 Cross 回答它們之間的空間關係。

01先準備兩支向量forward / toTarget 02Dot前方還是後方 03Cross左方還是右方 04遊戲用途AI、視野、轉向 05課程校正平行、浮點數、順序
01

先準備兩支箭：我的前方、目標方向

老師的測試場景把白色 Cube 當 A，紅色 Cube 當 B / Target。程式先取得 A 的前方，再算出從 A 指向 B 的向量：

Vector3 forward = transform.TransformDirection(Vector3.forward);
Vector3 toOther = target.position - transform.position;

toOther 的意思非常重要：用「目標位置 - 自己位置」，得到一支從自己指向目標的箭。

自己 A ● ─────────→ ● B 目標
         toOther

這個例子裡，transform.TransformDirection(Vector3.forward) 是把本地座標的正前方轉成世界座標方向。若目的只是取得物件目前朝向，通常也可以直接使用：

Vector3 forward = transform.forward;
先準備好問題forward = 我朝哪裡；toOther = 目標在我哪個方向。
02

Vector3.Dot：目標在前面還是後面？

Dot（點積）比較兩支向量的方向關係，回傳的是一個 float。這堂可以先把它理解成：「目標方向和我的正前方有多一致？」

float dot = Vector3.Dot(forward, toOther);

if (dot > 0)
{
    // 目標在前半邊
}
else if (dot < 0)
{
    // 目標在後半邊
}
else
{
    // 兩個方向互相垂直，目標在正側方
}
Dot > 0   → 大致同方向 → 前方
Dot < 0   → 大致反方向 → 後方
Dot = 0   → 互相垂直   → 正側方

因此 Dot 很適合回答「他是不是在我看的這一邊？」

Dot前後找 Dot。回傳 float，看正負就能知道目標在前半邊還是後半邊。
03

Vector3.Cross：目標在左邊還是右邊？

Cross（外積）和 Dot 不同，它回傳的是一個新的 Vector3。這個新向量會垂直於原本兩支向量形成的平面。

Vector3 cross = Vector3.Cross(forward, toOther);

老師的場景是在水平面上判斷左右，因此看結果的 y 正負：

if (cross.y > 0)
{
    // 右方
}
else if (cross.y < 0)
{
    // 左方
}
else
{
    // 沒有左右偏移
}

在老師使用的參數順序 Cross(forward, toOther) 下，可以用這個方式做左右判斷。

Cross左右找 Cross。回傳 Vector3；在這個水平面範例中，看 cross.y 的正負判斷左右。
04

這兩個在遊戲裡到底拿來幹嘛？

兩個 Cube 只是示範。真正有用的是「相對方向判斷」：

Dot：前後、視野、背面

Vector3 toPlayer = player.position - transform.position;
float dot = Vector3.Dot(transform.forward, toPlayer);

if (dot > 0)
{
    // 玩家在敵人的前半邊
}
else
{
    // 玩家在敵人的後半邊
}

常見用途：敵人視野、NPC 是否面向玩家、背刺判定、攻擊是否來自背後、角色前方互動。

Cross：左右、轉向方向

Vector3 toPlayer = player.position - transform.position;
float crossY = Vector3.Cross(transform.forward, toPlayer).y;

if (crossY > 0)
{
    // 目標偏右，往右轉
}
else if (crossY < 0)
{
    // 目標偏左，往左轉
}

常見用途：敵人追蹤時決定左轉或右轉、車輛 / 飛機 steering、瞄準轉向、判斷物件位於自身哪一側。

兩個一起用：知道目標在哪一象限

Dot       → 前 / 後
Cross.y   → 左 / 右

兩者組合：
前 + 右 → 右前方
前 + 左 → 左前方
後 + 右 → 右後方
後 + 左 → 左後方
遊戲直覺Dot =「你在我前面還後面？」；Cross =「你在我左邊還右邊？」
05

課程校正：有三個地方不要死背

1. Dot = 0 不是「平行」

老師範例在 dot == 0 時輸出「平行」，但向量數學上 Dot = 0 表示兩向量互相垂直。放到這個遊戲情境，就是目標位於物件的正側方。

2. 浮點數不要太依賴 == 0

課程為了示範寫 dot == 0 很直觀，但實際程式計算可能得到非常接近 0 的小數。需要判斷「接近垂直」時，可使用容許誤差：

if (Mathf.Abs(dot) < 0.001f)
{
    // 視為接近垂直
}

3. Cross 有順序

Vector3.Cross(forward, toOther)
Vector3.Cross(toOther, forward)

兩者結果方向相反。因此不能脫離參數順序死背「cross.y > 0 永遠等於右」。老師這堂的左右規則，是建立在 Cross(forward, toOther) 這個順序上。

先別急著背公式

這堂老師的目標是學會使用 Dot / Cross 做方向判斷，不是推導向量數學。先知道它們各自在回答什麼空間問題，比現在硬背外積公式有價值得多。
