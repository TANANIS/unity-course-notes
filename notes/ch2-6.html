ch2_6 while 迴圈

while 會在條件為 true 時持續重複執行。和 for 相比，它更直接地把重點放在「這個條件還成立嗎？」。

WHILE LOOP

條件成立就繼續，條件失敗才離開

這堂用角色 HP 當條件：只要 HP 還大於 0，就持續執行迴圈；每跑一圈消耗一些 HP，直到條件不再成立。

01基本結構while (condition) 02無限迴圈條件必須有機會改變 03Random.Range隨機初始 HP
01

while 的基本結構

int hp = 50;
int count = 0;

while (hp > 0)
{
    count++;
    Debug.Log("跑了 " + count + " 圈");
    hp--;
}
while (hp > 0)
每一輪開始前先檢查條件。只要仍為 true，就繼續進入迴圈。
count++
記錄目前已經執行幾次。
hp--
讓 HP 每輪減少，最後使 hp > 0 變成 false，迴圈才能結束。
一句話記憶while 不管你想跑幾次，它只管「條件還成立嗎？」
02

小心無限迴圈

老師特別提醒：如果 while 的條件一直成立，而且迴圈內又沒有任何東西讓它改變，程式就會不停執行。

int hp = 50;

while (hp > 0)
{
    Debug.Log("一直跑");
    // hp 沒有改變
}

這個例子裡 hp 永遠大於 0，所以條件永遠是 true。課堂示範因此加入 HP 遞減，讓迴圈最終可以停止。

重要

寫 while 時，要確認迴圈內或外部狀態真的有機會讓條件變成 false。

03

用隨機 HP 觀察 while 執行次數

字幕中的 API 名稱辨識很亂，但依老師描述的寫法與輸出範圍，這段是在用 Unity 的 Random.Range 產生整數 HP。

int hp = Random.Range(1, 101);
int count = 0;

while (hp > 0)
{
    count++;
    hp--;
}

Debug.Log("總共跑了 " + count + " 圈");

老師說明整數版本的範圍上限不包含在結果內，因此 Random.Range(1, 101) 會得到 1～100；若寫成 Random.Range(1, 50)，則是 1～49。

因為初始 HP 每次都不同，所以迴圈實際跑的次數也會不同。

本堂結論for 常用來管理已知的重複次數；while 則更適合表達「只要條件成立就繼續」。
