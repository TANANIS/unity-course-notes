ch3_6 Time_簡介

這堂開始整理 Unity 的時間相關靜態屬性。老師主要比較 Time.time 與 Time.realtimeSinceStartup，再介紹 Time.deltaTime 與 Time.timeScale，把上一堂 MoveTowards 裡出現的時間概念正式接起來。

TIME · DELTATIME · TIMESCALE

同樣都是「時間」，先分清楚遊戲時間、真實時間與每幀時間

這堂不是要背四個名字，而是要知道它們各自在回答不同問題：遊戲跑多久、現實過多久、這一幀花多久，以及整個遊戲時間要跑多快。

01Time 的靜態屬性直接 Time.xxx 使用 02Time.time遊戲累積時間 03realtimeSinceStartup真實經過時間 04deltaTime這一幀花多久 05timeScale遊戲時間倍率 06補充理解為什麼速度要乘 deltaTime
01

Time 這堂介紹的都是靜態屬性

老師先提醒，這些屬性都是靜態的，因此直接從 Time 使用，不需要先建立 Time 物件。

Time.time
Time.realtimeSinceStartup
Time.deltaTime
Time.timeScale
接回 staticTime.xxx = 直接從 Time 類別取得全域時間資訊。
02

Time.time：遊戲累積運行了多久

老師把 Time.time 描述為遊戲運行了多久的時間，並特別拿它和 realtimeSinceStartup 比較。

這堂最需要先記的是：Time.time 會受到 Time.timeScale 影響。也就是當遊戲時間被放慢或加速時，這個累積時間也會跟著改變速度。

Time.time把它想成「遊戲世界的手錶」：會跟著 timeScale 一起變快或變慢。
03

Time.realtimeSinceStartup：不受 timeScale 影響的真實時間

老師把 Time.realtimeSinceStartup 和 Time.time 放在一起比較，指出前者不會受到 timeScale 影響。

Time.time
→ 受 Time.timeScale 影響

Time.realtimeSinceStartup
→ 不受 Time.timeScale 影響

老師也提到，這類不受遊戲時間倍率影響的時間資訊，常會在 UI 動畫等需求中使用。

這堂先不硬背起算點細節

老師另外提到兩者開始計算的時間點不同。這裡先保留課堂脈絡，不把它擴寫成精確 API 規則；下一堂實際跑程式時再配合結果理解。

兩支手錶Time.time 看遊戲時間；realtimeSinceStartup 看不受 timeScale 影響的真實經過時間。
04

Time.deltaTime：上一幀到這一幀經過多少秒

老師將 Time.deltaTime 描述為「每一個 Frame 運行的時間」，單位是秒。這正是上一堂 MoveTowards 中 Time.deltaTime * speed 的來源。

Time.deltaTime
= 這一幀經過多少秒

因此如果 speed 的意思是「每秒移動多少單位」，就可以：

float distanceThisFrame = speed * Time.deltaTime;
每秒速度 × 這幀經過的秒數
= 這一幀應該移動的距離
deltaTime把「每秒多少」換算成「這一幀該做多少」。
05

Time.timeScale：控制遊戲時間的快慢

老師介紹 Time.timeScale 時，將它用在快動作與慢動作效果。它可以控制遊戲時間的倍率。

Time.timeScale = 1f;   // 正常速度
Time.timeScale = 0.5f; // 慢動作
Time.timeScale = 2f;   // 快動作
Time.timeScale = 0f;   // 遊戲時間停止

課堂同時強調：timeScale 會影響 Time.time，但不會影響 Time.realtimeSinceStartup。

timeScale它不是「現在幾秒」，而是控制遊戲世界的時間流速倍率。
06

補充理解：為什麼移動速度通常要乘 deltaTime？

這一段是課後補充，用來把上一堂 MoveTowards 和這堂 Time 串起來。若直接在 Update() 裡每幀固定移動相同距離，那每秒移動多少會跟 FPS 有關。

// 每一幀都走 0.1
transform.position += Vector3.forward * 0.1f;

60 FPS 時一秒會執行約 60 次，120 FPS 時約 120 次，因此高 FPS 反而走得更快。改成：

transform.position += Vector3.forward * speed * Time.deltaTime;

就把意義改成「每秒以 speed 移動」，每幀實際走多少則交給 deltaTime 換算。

speed
= 每秒速度

Time.deltaTime
= 這幀經過的秒數

speed * Time.deltaTime
= 這幀距離
真正用途deltaTime 讓每幀執行的 Update 邏輯，能用「每秒速度」來描述，而不是綁死在 FPS 上。
07

四個 Time 屬性先用四句話記

Time.time
= 遊戲累積時間，受 timeScale 影響

Time.realtimeSinceStartup
= 真實經過時間，不受 timeScale 影響

Time.deltaTime
= 上一幀到這一幀經過多少秒

Time.timeScale
= 遊戲時間流速倍率
這堂核心deltaTime 解決「每幀」與「每秒」的換算；timeScale 控制遊戲時間到底流多快。
