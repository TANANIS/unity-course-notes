ch2_2 變數計算

這堂把變數拿來做實際運算：數值的加減乘除、布林邏輯，以及遊戲裡很常見的累加與遞增寫法。

OPERATORS

變數不只是保存資料，也會參與運算

數值可以計算，布林值可以組合條件，而複合指定可以把「取出舊值、計算、再存回去」寫得更簡潔。

01

數值的基本四則運算

int a = 20;
int b = 10;

int add = a + b;
int subtract = a - b;
int multiply = a * b;
int divide = a / b;
+
加法
-
減法
*
乘法
/
除法

遊戲中的 HP、攻擊力、金錢、經驗值與速度等數值，都會大量使用這些基本運算。

02

整數除法會捨去小數部分

int a = 10;
int b = 20;

int result = a / b;   // 0

當兩個運算元都是整數時，除法結果也會以整數方式處理，所以 10 / 20 不會得到 0.5，而是 0。

如果希望保留小數，運算中要有浮點數，結果也要用能承接浮點數的型別：

float a = 10f;
int b = 20;

float result = a / b;   // 0.5
本堂重要觀念運算元的型別會影響運算結果；做除法時特別注意是不是兩邊都是 int。
03

bool 的邏輯運算

bool hasFireStone = true;
bool hasWaterStone = false;

bool canOpenGate = hasFireStone && hasWaterStone;
bool hasAnyStone = hasFireStone || hasWaterStone;
bool noFireStone = !hasFireStone;
&& AND
兩邊都為 true 才會得到 true。老師用「火之石與水之石都要有才能開門」舉例。
|| OR
只要其中一邊為 true，結果就是 true。老師用「受到攻擊或中毒都會扣血」舉例。
! NOT
把布林值反轉：true 變 false，false 變 true。
04

複合指定運算子

int count = 0;

count += 2;
count += 5;

Debug.Log(count);   // 7

count += 2 可以理解成把原本的 count 加 2，再把結果存回 count。

count += 2;   // 加
count -= 2;   // 減
count *= 2;   // 乘
count /= 2;   // 除

這類寫法在遊戲數值更新時很常見，例如扣血可以用 hp -= damage;。

05

只加一或減一：++ / --

count++;
count--;
count++
讓 count 增加 1。
count--
讓 count 減少 1。

如果不是加減 1，就改用 +=、-= 等複合指定運算子。

老師順帶示範

為了暫時忽略一段測試程式碼，可以使用 /* ... */ 多行註解。這只是課堂示範的小工具，不是本堂主要內容。

本堂結論數值用運算子計算，條件用布林運算組合；需要反覆更新同一個變數時，複合指定會很常出現。
