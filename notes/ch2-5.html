ch2_5 for 迴圈

for 適合處理「重複執行固定次數」的情況。老師用跑操場 10 圈當例子，示範迴圈如何自己計數並在條件不成立時停止。

LOOP

初始化 → 檢查條件 → 執行 → 更新

for 小括號裡有三個區塊，由兩個分號隔開。每跑完一輪，就更新計數值，再重新檢查條件。

01基本結構三個區塊 02執行流程跑 10 圈 03作用域i 只活在迴圈裡
01

for 的基本結構

for (int i = 1; i <= 10; i++)
{
    Debug.Log("跑了 " + i + " 圈");
}
int i = 1
初始化。迴圈開始前先建立計數變數。
i <= 10
條件。只要條件是 true，就繼續執行迴圈。
i++
每輪結束後執行的更新。這裡代表 i 每次加 1。
一句話記憶for = 從哪裡開始、什麼時候繼續、每輪結束後怎麼更新。
02

迴圈會怎麼跑？

  1. 01
    建立 i = 1

    初始化只在最開始執行一次。

  2. 02
    檢查 i <= 10

    成立就進入迴圈內容。

  3. 03
    執行大括號內容

    例如印出目前跑到第幾圈。

  4. 04
    執行 i++

    每跑完一輪，計數值加 1，再回去檢查條件。

當 i 變成 11 時，11 <= 10 為 false，因此離開迴圈。

03

for 裡宣告的變數有自己的作用域

for (int i = 1; i <= 10; i++)
{
    Debug.Log(i);
}

// Debug.Log(i);  // 這裡不能再使用 i

老師特別提醒：如果 i 是在 for 裡宣告的，它只存在於這個迴圈的作用範圍內。離開迴圈後就不能再使用。

本堂結論需要重複固定次數時，for 會幫你管理計數、條件與每輪更新。
