ch1_4 移除物件與建立空白物件

處理 GameObject 的刪除、命名與 Empty GameObject，並釐清新版 Unity 中 Scene 圖示為何可能沒有顯示。

DELETE / RENAME / EMPTY / ICON

Empty GameObject 看不見，不代表它不存在

它只是沒有 Renderer。Unity 沒有把物件吞掉，只是終於有一次忠實地呈現「沒有可渲染內容」這件事。

01刪除與改名Delete、Rename、F2 02建立空白物件只有 Transform 的容器 03指定 Scene 圖示Label、Image、Other 04圖示沒有顯示Gizmos 與 3D Icons
01

刪除與重新命名 GameObject

Delete
在 Hierarchy 或 Scene 選取 GameObject 後按 Delete，可將它從目前 Scene 中移除。
Hierarchy 右鍵 → Delete
在 Hierarchy 對物件按右鍵，再選擇 Delete，結果相同。
Inspector 名稱欄位
選取 GameObject 後，可直接修改 Inspector 最上方的名稱。
Hierarchy 重新命名
選取物件後再次點擊名稱，或按 F2，再輸入新名稱。
Undo
誤刪或改錯時可先嘗試 Ctrl+Z 復原。不要把 Delete 當成測試膽量的按鈕。
「點兩下」要講精確

快速雙擊 Hierarchy 項目常用來在 Scene 中定位或聚焦物件；重新命名通常是先選取，再次點名稱，或直接按 F2。兩個操作看似都用了兩次滑鼠，行為卻不是同一件事。

Hierarchy 與 Project 的 Delete 不同

在 Hierarchy 刪除的是目前 Scene 裡的 GameObject；在 Project 刪除的則是 Asset 檔案。刪一個場景實例與刪掉專案資源，後果差得很有教育意義。

02

Create Empty：建立空白 GameObject

可從上方選單 GameObject → Create Empty，或在 Hierarchy 空白處按右鍵選擇 Create Empty。

預設內容
Empty GameObject 預設只有 Transform，沒有 Mesh Filter、Renderer 或 Collider。
為什麼看不見？
它沒有 Renderer，因此 Game 覛窗不會畫出任何外觀；Scene 覛窗中通常只能看到 Transform 操作軸、選取外框或額外指定的圖示。
整理階層
可當作父物件，將多個物件組成一組，例如 Enemies、Environment、SpawnPoints。
座標基準
可作為旋轉中心、出生點、攝影機目標、路徑節點或其他空間參考點。
掛載功能
可附加管理腳本、Audio Source 或其他不需要外觀的 Component。
一句話記憶 Empty GameObject 是只有 Transform 的場景容器與座標節點，不是空白 Asset，也不是不存在的物件。
拿來分組時先整理 Transform

若 Empty 只是階層群組，通常讓 Rotation 保持 0, 0, 0、Scale 保持 1, 1, 1，並確認 Position 是否符合用途。否則子物件會繼承一堆日後很難解釋的偏移與縮放。

03

替看不見的物件指定 Scene 圖示

選取 GameObject，在 Inspector 最上方名稱左側按下 Select Icon，即可指定編輯器圖示。這只協助編輯，不會變成遊戲中的實際畫面。

Label Icon
在 Scene 覛窗顯示彩色標籤與 GameObject 名稱，適合需要直接辨認用途的節點。
Image-only Icon
只顯示小型彩色圖示，不顯示物件名稱，適合 Spawn Point、Waypoint 等大量節點。
Other…
從 Project 中選擇圖片作為自訂圖示，例如危險區、互動點或任務標記。
None
移除自訂圖示，恢復預設圖示。
圖示不是 Component，也不是 Renderer

它是 Unity Editor 的工作標記，只用來幫助開發者在 Scene 中找物件。建置遊戲後，玩家不會看到這個標記。

04

新版 Unity 指定圖示後，為什麼 Scene 沒顯示？

功能沒有被新版移除。Unity 6 仍支援替 GameObject 指定圖示；顯示與否改由 Scene 視窗的 Gizmos 設定共同控制。

  1. 01
    確認 Scene 的 Gizmos 已開啟

    查看 Scene 覛窗右上方的 Gizmos 按鈕。主開關關閉時，自訂圖示與其他 Gizmo 都不會顯示。

  2. 02
    展開 Gizmos 選單

    在 Recently Changed、Scripts 或其他對應項目中，確認圖示欄沒有被關閉。全彩圖示表示會顯示，淡色圖示表示被隱藏。

  3. 03
    檢查 3D Icons 大小

    若啟用 3D Icons，圖示會依距離縮放，也可能被場景幾何遮住。把滑桿拉大，或暫時關閉 3D Icons，讓圖示以固定大小顯示在物件上方。

  4. 04
    檢查 Fade Gizmos

    若啟用 Fade Gizmos，畫面上太小的 Gizmo 可能被淡出甚至停止繪製。測試時可先關閉。

  5. 05
    重新指定一個明顯圖示

    先選擇 Label Icon 或顏色明顯的 Image-only Icon，再拉近 Scene Camera，排除圖示太小、被遮擋或選到 None 的情況。

最可能的原因

依你描述的情況，優先檢查 Scene 右上角 Gizmos 主開關、Gizmos 選單中的圖示可見性，以及 3D Icons 滑桿。這比直接判定「新版不能顯示」合理得多，軟體雖然常把按鈕搬家，還不至於每版都銷毀一項基本功能。

排查順序 Select Icon 已指定 → Gizmos 開啟 → 圖示項目可見 → 調整 3D Icons／Fade Gizmos → 拉近 Scene Camera。
