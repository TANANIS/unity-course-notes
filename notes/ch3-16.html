ch3_16 碰撞器（Collision）

這堂先把 Unity 的碰撞想成兩種門：一種是「真的牆」，撞到會被擋住；另一種是「感應門」，可以穿過去，但 Unity 會知道你進來了。

COLLIDER · COLLISION · TRIGGER · RIGIDBODY

撞牆，和走進感應區，是兩件不同的事

牆壁需要真的擋住角色；金幣、NPC 感應區或事件區域通常只需要知道「有人進來」，不一定要把人彈回去。Unity 用 Collision 和 Trigger 把這兩種需求分開。

01

先分兩種：真的撞到，和只是「被偵測到」

課程把碰撞分成兩類：

Collision
→ 像牆壁
→ 你撞到它，它會擋住你
→ 彼此不能直接穿過

Trigger
→ 像感應門 / 金幣區域
→ 你可以穿過去
→ 但 Unity 仍然知道你進來了

五歲版：Collision 是「門真的鎖著」；Trigger 是「門打開了，但門口有感應器」。

一句話記憶Collision 會擋；Trigger 不擋，但會通知你有人經過。
02

Is Trigger：把 Collider 從「牆」改成「感應區」

Collider 原本可以拿來阻擋物件。把 Collider 上的 Is Trigger 勾起來後，課程示範物件就能穿過，不再互相阻擋。

Is Trigger = OFF
→ 這是一面牆
→ 撞到會被擋住

Is Trigger = ON
→ 這是一個感應區
→ 可以穿過，但仍可收到 Trigger 事件

課程用金幣作例子：角色走過金幣時，不希望被金幣卡住，只希望知道「角色碰到金幣了」，然後執行後續行為。

Is Trigger勾起來不是「沒有碰撞」，而是從物理阻擋改成只做進出偵測。
03

課程測試：Cube 加 Rigidbody，再拿去撞 Cube2

課程的測試設定是：

Cube
├─ Collider
├─ Rigidbody
└─ TestCollision

Cube2
└─ Collider

課程把 Cube 的 Rigidbody 加上去，並先取消 Use Gravity，這樣手動拖動 Cube 測試碰撞時比較容易觀察，不會一直被重力拉走。

接著用編輯器把 Cube 推向 Cube2：

Cube → Cube2

Is Trigger 關閉
→ Cube 會被擋住

Is Trigger 開啟
→ Cube 可以穿過

課程還示範 Trigger 模式下，碰到的物件可以透過程式被刪除，因此看起來會「一碰就消失」。

測試重點先用同一對物件切換 Is Trigger，最容易看懂「阻擋」和「只偵測」的差別。
04

四個常用事件：進來和離開，各有 Collision / Trigger 版本

課程主要介紹四個常用方法：

OnCollisionEnter(...)
→ 開始撞到普通 Collider

OnCollisionExit(...)
→ 離開普通 Collider

OnTriggerEnter(...)
→ 進入 Trigger 區域

OnTriggerExit(...)
→ 離開 Trigger 區域

五歲版可以想成門口警衛：

Enter
→「有人進來了！」

Exit
→「那個人出去了！」

差別只在這個門是「真的牆」還是「感應區」。沒有勾 Is Trigger 時走 Collision 那組；勾了之後走 Trigger 那組。

課程範例

課程在 Trigger 進入事件中示範刪除碰到的物件，所以物件穿過 Trigger 時會直接消失。重點不是「Trigger 會自動刪除」，而是 Trigger 事件被觸發後，程式選擇執行刪除。

事件選擇普通 Collider 看 OnCollision...；Is Trigger 勾起來看 OnTrigger...
05

只有 Collider 還不夠：課程要求其中一邊要有 Rigidbody

課程特別提醒：兩個互動的物件不能只有 Collider，其中至少一邊需要有 Rigidbody，否則這堂示範的碰撞 / Trigger 回呼不會照預期出現。

物件 A：Collider + Rigidbody
物件 B：Collider
→ 可以做這堂的碰撞事件測試

物件 A：只有 Collider
物件 B：只有 Collider
→ 課程提醒：不會有預期的事件反應

五歲版：Collider 像「身體外框」，Rigidbody 像跟物理系統辦了一張身分證。至少要有一個人真的登記進物理系統，Unity 才會照這堂的方式處理事件。

Rigidbody兩個 Collider 要互動時，先檢查其中至少一邊有沒有 Rigidbody。
06

不要背一堆詞，先問「我要不要擋住它？」

我要它真的擋住玩家嗎？

YES
↓
普通 Collider
↓
Collision
↓
OnCollisionEnter / Exit

NO，只想知道有人經過
↓
勾 Is Trigger
↓
Trigger
↓
OnTriggerEnter / Exit

典型例子：

牆、地板、建築物
→ Collision

金幣、事件區、NPC 感應範圍
→ Trigger
這堂核心Collider 決定「哪裡算碰到」；Is Trigger 決定「要不要真的擋住」；Rigidbody 讓物理互動能被系統處理。
