ch2_1 變數宣告

先決定資料要用什麼型別保存，再給它一個有意義的名稱與初始值。這堂只處理 C# 最基本、也最常見的四種型別。

TYPE / NAME / VALUE

變數就是「型別 + 名稱 + 值」

老師用杯子比喻變數：不同資料需要不同容器。實際寫程式時，型別決定變數能保存什麼資料與可進行哪些操作。

01宣告與賦值type name = value 02基本型別int / float / string / bool 03命名規則不要從數字開始 04Debug.Log把值印到 Console 05Unity 補充Start 與 Component
01

宣告、命名、賦值

基本語法可以拆成三個部分：

int hp = 100;
//  ^   ^    ^
// 型別 名稱  值
型別（type）
決定這個變數可以保存哪一類資料，例如整數、浮點數、文字或布林值。
變數名稱
讓程式設計者知道這個值代表什麼。hp 比 a 更容易理解。
=
這裡是「賦值」，把右邊的值交給左邊的變數，不是數學上的相等判斷。
;
C# 陳述式通常以分號結尾。
一句話記憶左邊決定「這是什麼」，右邊提供「它現在是多少」。
02

四種基本型別

int hp = 100;
float speed = 7.5f;
string message = "成功";
bool isOpen = false;
int
32 位元整數，不包含小數。範圍是 -2,147,483,648 到 2,147,483,647；通常不需要背範圍。
float
單精度浮點數，Unity 的座標、速度與許多數值都常使用它。小數常值通常要加 f，例如 7.5f。
string
文字資料，內容放在雙引號中，例如 "Hello"。
bool
只有 true 與 false，適合表示開／關、成立／不成立等二元狀態。
為什麼 float 要寫 f？

C# 中像 7.5 這種沒有後綴的小數常值預設是 double。若要直接指定給 float，寫成 7.5f。

03

變數名稱的基本規則

不能以數字開頭
1hp 不合法；hp1 可以。
底線可以使用
_hp 是合法名稱。
不要亂塞符號
一般識別字不會使用 %、#、- 等符號。
名稱要表達用途
初學階段先養成可讀性。區域變數常見寫法是 camelCase，例如 moveSpeed、playerHp。
先不要背整份語言規格

這堂只需要掌握「名稱不要從數字開始、不要亂用符號、名稱要能看懂」即可。C# 識別字的完整規則比這更細，但現在背它沒有任何收益。

04

用 Debug.Log 查看變數

int hp = 100;
Debug.Log("HP: " + hp);

執行後，Unity Console 會看到：

HP: 100
Debug.Log(...)
把訊息輸出到 Unity Console，是最基本的檢查與除錯方式。
+ 與字串
其中一邊是 string 時，這裡的 + 會進行字串串接，hp 會轉成文字後接在後面。
05

這堂在 Unity 裡實際做了什麼

老師把練習程式寫在 Start()，再把 Script 掛到場景中的 GameObject 上，按下 Play 後由 Unity 執行 Start()，因此 Console 才會出現 Debug.Log 的內容。

Start()
這堂用它當練習入口；老師也說若沒有特別說明，後續基礎語法練習會先放在這裡。
掛上 Script
只有把這個 MonoBehaviour Script 作為 Component 掛到啟用中的 GameObject，Unity 才會在執行時呼叫它的生命週期方法。
這堂的變數
若宣告在 Start() 內，它們屬於區域變數，只在該方法的作用域中使用。Inspector 欄位是另一個概念，之後再處理。
本堂結論先選資料型別，再取有意義的名稱；需要確認值時就用 Debug.Log。
