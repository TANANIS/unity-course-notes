ch1_7 Tag 與 Layer

Tag 用來辨認物件身分；Layer 用來讓物理、Raycast、Camera 等系統篩選物件。

IDENTITY / FILTERING

它是誰，和系統要不要處理它，是兩件事

老師用「大分類／小分類」解釋 Layer 與 Tag，勉強能入門，但真正穩定的記法是：Tag 偏向身分，Layer 偏向引擎篩選。

01

Tag 與 Layer 位於 Inspector 上方

選取 GameObject 後，Inspector 最上方會看到 Tag 與 Layer 下拉選單。這兩者都不是 Component，而是 GameObject 本身的基本設定。

02

課程中的配色準備：建立 Material

字幕中的「meteor」實際上是 Material（材質）。老師先替 Cube 與 Sphere 套上不同顏色，目的是讓後面的 Tag／Layer 示範比較容易辨認，並不是 Tag 或 Layer 自己會控制顏色。

  1. 01
    在 Project／Assets 空白處按右鍵

    選擇 Create → Material，建立一個 Material Asset。

  2. 02
    選取 Material

    在 Inspector 修改材質顏色。URP 常見欄位是 Base Map；舊版 Standard Shader 常見名稱是 Albedo。

  3. 03
    把 Material 套到物件

    將 Material 從 Project 拖到 Scene 中的物件，或指定到 Mesh Renderer → Materials → Element 0。

流程Project 建立 Material → Inspector 調顏色 → 拖到 GameObject 或指定給 Mesh Renderer。
不是「右鍵直接選顏色」

右鍵做的是建立 Material；顏色是在選取 Material 後，由 Inspector 調整。GameObject 只是透過 Mesh Renderer 引用這個材質。三個步驟被老師講得很快，但概念不能因此揉成一團。

03

Tag：表示物件是什麼

用途
替 GameObject 加上身分標籤，例如 Player、Enemy、Collectible。
數量
可建立多個自訂 Tag，但一個 GameObject 同一時間只能指定一個 Tag。
新增
從 Tag 下拉選單進入 Add Tag...，新增後仍要回到原物件重新指定。
刪除
若某 Tag 正被物件使用，先把物件改成 Untagged 或其他 Tag，再移除該 Tag。
程式判斷
常用 CompareTag("Enemy") 判斷碰撞或觸發到的物件身分。
不要把多重屬性全部塞進 Tag

一隻敵人可能同時是 Enemy、Dragon、Fire、Boss，但它不能同時擁有四個 Tag。多重屬性更適合 enum、自訂 Component 或 ScriptableObject。

04

Layer：讓系統篩選物件

用途
用於 Physics Collision Matrix、Raycast LayerMask、Camera Culling Mask、Light 等系統過濾。
範圍
Layer 索引為 0～31，共 32 層；通常可自行命名的是 8～31，共 24 層。
新增
從 Layer 下拉選單進入 Add Layer...，建立名稱後仍要回到 GameObject 實際指定。
LayerMask
LayerMask 使用 32 個 bit 表示要包含哪些 Layer；GameObject 的 layer 則只是 0～31 的單一索引。
位元觀念GameObject.layer 是索引；LayerMask 才是用 32 個 bit 同時選擇多個 Layer。
05

Tag 與 Layer 怎麼選

它是誰？
用 Tag。例如角色是否為 Player、Enemy、Collectible。
物理要不要碰撞？
用 Layer 與 Physics Collision Matrix。
Raycast 要不要打到？
用 LayerMask。
Camera 要不要拍到？
用 Layer 與 Culling Mask。
一句話記憶Tag 辨認身分；Layer 過濾系統行為。
老師的「Layer 大分類、Tag 小分類」不夠準

分類大小不是核心。Tag 與 Layer 的差別在使用場景，不在誰比較大。照「大／小」硬套，後面很容易把 Dragon、Fire、Boss 全部亂塞進單一 Tag。
