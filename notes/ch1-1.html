ch1_1 開啟新專案

認識 Unity Hub 中建立、開啟與管理專案的基本流程。

01

核心操作

Projects
查看並開啟已存在於清單中的專案。
New
建立新的 Unity 專案。
Open
開啟未列在 Unity Hub 清單中的既有專案資料夾。
02

建立新專案流程

  1. 01
    選擇 New Project

    從 Unity Hub 建立新專案。

  2. 02
    設定專案名稱

    建議使用英文與清楚一致的命名。

  3. 03
    選擇儲存路徑

    固定、容易找到，而且納入備份。

  4. 04
    選擇範本

    依專案需求選擇 2D 或 3D。

  5. 05
    建立專案

    確認設定後按下 Create。

觀念校正

課程提到「C 槽容易損毀」並不精確。真正要控制的是系統重灌、容量不足、資料散落與沒有備份的風險。重點不是迷信磁碟代號，而是固定路徑、版本控制與備份。

一句話記憶New Project → 命名 → 選路徑 → 選 2D／3D → Create
