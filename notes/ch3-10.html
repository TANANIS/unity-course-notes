ch3_10 RigidbodyAnComponent_2（物理元件介紹）

這堂把上一堂的 Rigidbody、GetComponent、Vector3 與 FixedUpdate 組成一個完整案例：Cube 以鍵盤輸入受力移動，Sphere 則在滑鼠按下後解除 Kinematic 並施力發射。

RIGIDBODY · INPUT · ADDFORCE · KINEMATIC

從取得輸入，到組成方向向量，再交給 Rigidbody 施力

這堂的價值不是多背一個 API，而是第一次把輸入、向量、Component 與物理系統串成可玩的操作流程。

01場景設定Cube 與 Sphere 的 Rigidbody 02鍵盤移動Input.GetAxis + AddForce 03取得元件GetComponent / InChildren 04發射子彈isKinematic + shootSpeed 05案例注意點GetMouseButton 與座標軸
01

Cube 與 Sphere 的 Rigidbody 設定

課程中的紅色 Cube 是可移動砲台。它有 Rigidbody、Box Collider 與 TestComponent，Inspector 中的移動速度設為 20。

Cube
├── Box Collider
├── Rigidbody
│   ├── Use Gravity = true
│   ├── Is Kinematic = false
│   └── Freeze Rotation
│       ├── X = true
│       ├── Y = false
│       └── Z = true
└── TestComponent
    └── Speed = 20

Freeze Rotation X / Z 可以避免物件受力後前後或左右翻滾；Y 軸保留，仍可允許水平轉向。

Sphere 則作為子彈，初始勾選 Is Kinematic，並停用 Sphere Collider。Shoot 元件中的發射向量設定為 (0, 50, 100)。

Sphere
├── Sphere Collider = Disabled
├── Rigidbody
│   ├── Use Gravity = true
│   └── Is Kinematic = true
└── Shoot
    └── Shoot Speed = (0, 50, 100)
一句話記憶Cube 一開始就是動態剛體；Sphere 則先以 Kinematic 等待發射。
02

Input.GetAxis 組成 X/Z 平面的施力方向

float x = Input.GetAxis("Horizontal");
float y = Input.GetAxis("Vertical");

Vector3 force = new Vector3(
    x * speed,
    0,
    y * speed
);

rigidbody.AddForce(force);

Horizontal 控制世界 X 軸左右；課程雖把 Vertical 存在變數 y，實際卻放到 Vector3 的 Z 分量，因為 3D 地面上的前後是 Z，而世界 Y 是上下。

Horizontal → X → 左右
Vertical   → Z → 前後
Y          → 0 → 不主動往天空施力

GetAxis 的輸入值大致位於 -1 到 1，因此再乘上 speed 放大力道，最後交給 Rigidbody 的 AddForce()。

資料流鍵盤輸入 → Vector3 方向 → × speed → Rigidbody.AddForce。
03

同一支腳本同時取得自己與子物件的 Component

private Rigidbody rigidbody;
private Shoot shootObj;

void Start()
{
    rigidbody = GetComponent<Rigidbody>();
    shootObj = GetComponentInChildren<Shoot>();
}

GetComponent<Rigidbody>() 取得 Cube 自己身上的 Rigidbody；GetComponentInChildren<Shoot>() 則往子階層找到 Sphere 上的 Shoot 元件。

Cube
├── Rigidbody ← GetComponent
└── Sphere
    └── Shoot ← GetComponentInChildren
Component 模型先取得元件參考，之後才能呼叫該元件提供的能力。
04

Sphere 發射：解除 Kinematic，再 AddForce

public Vector3 shootSpeed;
private Rigidbody shootRigidbody;

void Start()
{
    shootRigidbody = GetComponent<Rigidbody>();
}

public void shoot()
{
    shootRigidbody.isKinematic = false;
    shootRigidbody.AddForce(shootSpeed);
}

Sphere 初始 isKinematic = true，因此先不由一般動態物理帶著移動。呼叫 shoot() 時改成 false，再施加 (0, 50, 100) 的力。

(0, 50, 100)
    ↑     ↑
   +Y    +Z
  往上   往前

因此子彈同時有向上與向前的初始力，加上已啟用的 Gravity，畫面會呈現拋射感。

發射流程isKinematic = false → AddForce(shootSpeed) → 重力持續作用。
05

案例裡值得特別記住的兩個細節

課程使用：

if (Input.GetMouseButton(0))
{
    shootObj.shoot();
}

這表示滑鼠左鍵只要維持按住，條件就會持續成立，而不是只在按下的瞬間觸發。這是本課範例的實際行為。

讀程式不要被變數名稱騙

課程把 Vertical 輸入存在名為 y 的變數，但最後使用的是 Vector3 的 Z 軸。判斷座標意義時要看資料最後放到哪個分量，而不是只看區域變數叫什麼。
