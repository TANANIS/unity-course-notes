ch2_7 陣列

陣列可以用同一個變數名稱保存多筆相同型別的資料，再透過索引指定要讀取哪一個元素。這堂只介紹最基本的一維陣列。

ARRAY

像一排有編號的抽屜

老師用抽屜比喻陣列：每一格都能放資料，而且每格都有編號。最重要的是，C# 陣列的索引從 0 開始。

01索引從 0 開始 02建立陣列string[] 03for 走訪Length 04foreach逐筆取得元素
01

索引從 0 開始

如果陣列有 3 個元素，它的索引不是 1～3，而是：

0  1  2

因此有 6 個元素時，最後一個索引會是 5。

一句話記憶陣列長度是 N，最後一個索引就是 N - 1。
02

建立與存取一維陣列

string[] names = new string[3];

names[0] = "Karen";
names[1] = "Howard";
names[2] = "Linda";
string[]
代表這是一個用來存放 string 的陣列。
new string[3]
建立一個長度為 3 的字串陣列。
names[2]
取得索引 2，也就是第三個元素。
Debug.Log(names[2]);   // Linda
03

用 for 從頭走過整個陣列

for (int i = 0; i < names.Length; i++)
{
    Debug.Log(names[i]);
}
i = 0
因為陣列索引從 0 開始，所以走訪也從 0 開始。
names.Length
取得陣列目前的元素數量。這個例子會得到 3。
i < names.Length
只跑到最後一個有效索引，避免超出陣列範圍。
04

只想逐筆讀取時，可以使用 foreach

foreach (string name in names)
{
    Debug.Log(name);
}

foreach 會依序把陣列中的每個元素取出，放進這裡的 name，直到全部走完。

老師認為這種寫法在單純逐筆讀取時可讀性比完整的 for 高；同時也提醒，不能因此直接認定 foreach 的效能一定比 for 快。

本堂範圍

C# 還有多維陣列，但老師這堂只先建立一維陣列的基本概念。

本堂結論陣列用索引管理同型別的多筆資料；索引從 0 開始，整批讀取時可以搭配 for 或 foreach。
