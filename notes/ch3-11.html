ch3_11 Transform_1（Transform 物件常用方法介紹）

這堂先建立 Transform 的總覽：它保存 GameObject 的位置、旋轉與縮放狀態，也提供常用的移動、座標轉換、旋轉與朝向方法。

TRANSFORM · POSITION · ROTATION · LOCAL / WORLD

Transform 描述物件的空間狀態，也提供改變空間狀態的方法

先把「目前是什麼狀態」與「從目前狀態再改多少」分開，後面的 API 會容易理解很多。

01三大狀態Position / Rotation / Scale 02常用屬性position / rotation / eulerAngles 03Translate在目前位置上增加位移 04TransformDirectionLocal → World 05Rotate / LookAt累加旋轉與朝向目標
01

Transform 的三大空間狀態

Transform
├── Position  位置
├── Rotation  旋轉
└── Scale     縮放

課程先回到 Inspector 的 Transform 元件。所有 GameObject 都會有 Transform，它用來描述物件在場景中的位置、旋轉與縮放。

三項資料都具有 X、Y、Z 三個方向，因此也會再次碰到 Unity 的 3D 座標與 Local / World 概念。

一句話記憶Transform 是 GameObject 的空間狀態核心。
02

position、rotation、eulerAngles

transform.position
→ Vector3
→ 物件位置

transform.rotation
→ Quaternion
→ 物件旋轉

transform.eulerAngles
→ Vector3
→ 用 X / Y / Z 角度表示旋轉

課程指出 Quaternion 是 Unity 常用的旋轉表示方式，但四個數值不容易直接看出「繞哪個軸轉幾度」；Euler Angle 則以 Vector3 的 X、Y、Z 角度表示，對人比較直觀。

因此實作時常會先用 Euler Angle 思考旋轉，再視需求轉成 Quaternion。

旋轉表示Euler Angle 比較直觀；rotation 使用 Quaternion。
03

Translate：在目前位置上增加位移

課程用位置 5、每次移動 2 的例子建立直覺：

5 → 7 → 9 → 11 → 13 ...

Translate() 的重點不是指定一個固定座標，而是從目前位置再移動指定向量。

transform.Translate(Vector3.forward * 2f);
和 position 分開理解

position = ... 描述或直接設定目前位置；Translate(...) 則是在目前位置基礎上再增加一段位移。

Translate不是「去哪裡」，而是「從現在再移多少」。
04

TransformDirection：Local direction 轉成 World direction

transform.TransformDirection(Vector3.forward)

課程先給出定義：將 Local Space 的方向轉換成 World Space。當物件已經旋轉時，「自己的前方」不一定等於世界座標的 +Z，因此需要把本地方向換算成世界方向。

Local forward
→ TransformDirection
→ World 中實際對應的方向
直覺「我的前方」轉成「在世界裡到底是哪個方向」。
05

Rotate 累加旋轉；LookAt 朝向目標

Rotate() 和 Translate 很像，重點是「在目前狀態上繼續增加」。課程以每次增加 20 度為例：

0° → 20° → 40° → 60° → ...

而 LookAt() 則用來讓物件看向指定目標。當目標移動到不同位置，物件可跟著改變 rotation 以維持朝向。

transform.Rotate(...);
transform.LookAt(target);
這堂核心position / rotation 描述狀態；Translate / Rotate 在目前狀態上持續改變。
