ch1_2 Unity3D 環境介紹

認識 Unity 的 File 選單、主要編輯器視窗、GameObject、Component，以及 Play Mode 的基本行為。

01

File 選單：Scene、Project 與建置

Save / Save As
儲存目前的 Scene；Scene 會以 .unity 場景資產存在專案中。
Save Project
儲存專案範圍的資產與設定變更，不應拿來取代目前 Scene 的儲存。
Build Profiles
設定要輸出的目標平台與建置選項，例如 Windows、WebGL、Android 或其他已安裝支援模組的平台。
Build And Run
建置遊戲，並在完成後直接執行。
版本差異

老師使用的舊版 Unity 將建置入口稱為 Build Settings；Unity 6 已改為 Build Profiles。核心目的仍包含選擇目標平台與設定建置內容，但新版可以針對平台建立並保存不同的建置設定檔。

02

五個主要區塊

Scene編輯場景與擺放物件
Hierarchy管理場景物件與父子層級
Inspector查看元件並修改屬性
Game查看攝影機實際輸出
Project管理圖片、模型、腳本與 Prefab 等資源
03

核心概念

GameObject
場景中的物件容器。
Component
附加在 GameObject 上，賦予物件資料或功能。
Rigidbody
讓物件受到 Unity 物理系統與重力影響。
04

播放控制

Play
執行遊戲。
Pause
暫停目前執行狀態。
Step
逐幀執行，用來觀察每一步變化。
Play Mode 警告

在 Play Mode 中修改 Inspector 數值，停止播放後通常會恢復原狀。播放中適合測試，不適合把正式設定只改在執行狀態裡。

一句話記憶Save 儲存場景，Save Project 儲存專案變更，Build Profiles 決定遊戲要用什麼設定輸出到哪個平台。

舊版課程提醒

老師畫面中的 Build Settings 在 Unity 6 已改為 Build Profiles。MonoDevelop、UnityScript／JavaScript、舊版 Preferences、Asset Store 視窗與 Navigation 流程等內容，也不必依照舊介面逐項照做。
