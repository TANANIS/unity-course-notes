ch1_2 Unity3D 環境介紹

認識 Unity 的 File、Edit 與 Preferences，以及主要編輯器視窗、GameObject、Component 和 Play Mode。

01

File 選單：Scene、Project 與建置

Save / Save As
儲存目前的 Scene；Scene 會以 .unity 場景資產存在專案中。
Save Project
儲存專案範圍的資產與設定變更，不應拿來取代目前 Scene 的儲存。
Build Profiles
設定要輸出的目標平台與建置選項，例如 Windows、WebGL、Android 或其他已安裝支援模組的平台。
Build And Run
建置遊戲，並在完成後直接執行。
版本差異

老師使用的舊版 Unity 將建置入口稱為 Build Settings；Unity 6 已改為 Build Profiles。核心目的仍包含選擇目標平台與設定建置內容，但新版可以針對平台建立並保存不同的建置設定檔。

02

Edit 選單與 Preferences

Cut / Copy / Paste
對目前選取的物件或資產進行剪下、複製與貼上；常用快捷鍵分別為 Ctrl+X、Ctrl+C、Ctrl+V。
Duplicate
複製目前選取內容，快捷鍵為 Ctrl+D。
Project Settings
修改目前專案的設定，例如輸入、物理、品質、標籤與平台相關設定。
Preferences
修改這台電腦上 Unity Editor 的個人偏好，例如腳本編輯器、顏色、快取與外部工具。
03

External Tools：程式編輯器與 Android 工具

External Script Editor
外部腳本編輯器。選擇雙擊 C# 腳本時要開啟的程式。本筆記使用 Visual Studio Code。
Android 工具的位置
Unity 6 仍從 Edit → Preferences → External Tools → Android 查看或指定 SDK、NDK、JDK 與 Gradle，並沒有搬到 Build Profiles。
Build Profile 的作用
在 Build Profiles 新增 Android Profile 並按下 Switch Profile，只會把 Android 設為目前專案的有效建置目標，不是顯示 External Tools Android 區塊的開關。
Android 區塊的前提
目前 Unity Editor 必須先安裝 Android Build Support，以及相依的 Android SDK & NDK Tools 和 OpenJDK。若未安裝，Build Profiles 會提供 Install with Unity Hub。
自訂路徑
預設建議使用 Unity Hub 安裝的相容版本。需要自訂時，取消勾選對應的 installed with Unity (recommended)，才能用 Browse 指定資料夾。
Android 區塊沒有出現

到 Unity Hub → Installs → 該 Editor 版本的設定選單 → Add modules，確認已安裝 Android Build Support、Android SDK & NDK Tools 與 OpenJDK，完成後重新啟動 Unity。單純切換 Android Build Profile 不會補裝這些工具。

04

Android 建置工具名詞

SDK
Software Development Kit，軟體開發套件。這裡指 Android SDK，提供 Android 平台 API、建置工具、裝置連線工具等，是「要把應用程式做成 Android App」所需的整套基礎工具。
NDK
Native Development Kit，原生開發套件。你的理解基本正確，它處理 Android 上的 C／C++ 原生程式碼。Unity 使用 IL2CPP 時，會先把 C# 編譯結果轉成 C++，再由原生工具鏈編譯成 Android 裝置能執行的程式，因此即使主要寫 C#，仍可能需要 NDK。
JDK
Java Development Kit，Java 開發套件。包含 Java 編譯器、執行環境與相關工具。Android 的建置流程仍依賴 Java 生態工具，所以 Unity 打包 Android 專案時需要它；不代表遊戲邏輯必須改用 Java 寫。
Gradle
建置自動化工具。負責依照建置腳本安排編譯、處理相依套件、整合資源，最後封裝成 APK 或 AAB。可以把它理解成 Android 打包流程的總管。
IL2CPP
Intermediate Language To C++。Unity 的 AOT 編譯後端，將 C# 編譯後的中間語言轉成 C++，再針對目標平台編譯成原生程式。
工具鏈關係C# 腳本可經 IL2CPP 轉成 C++；NDK 編譯原生程式，SDK 提供 Android 平台工具，JDK 與 Gradle 協助完成建置與封裝。
05

五個主要區塊

Scene編輯場景與擺放物件
Hierarchy管理場景物件與父子層級
Inspector查看元件並修改屬性
Game查看攝影機實際輸出
Project管理圖片、模型、腳本與 Prefab 等資源
06

核心概念

GameObject
場景中的物件容器。
Component
附加在 GameObject 上，賦予物件資料或功能。
Rigidbody
讓物件受到 Unity 物理系統與重力影響。
07

播放控制

Play
執行遊戲。
Pause
暫停目前執行狀態。
Step
逐幀執行，用來觀察每一步變化。
Play Mode 警告

在 Play Mode 中修改 Inspector 數值，停止播放後通常會恢復原狀。播放中適合測試，不適合把正式設定只改在執行狀態裡。

舊版課程提醒

老師畫面中的 Build Settings 在 Unity 6 已改為 Build Profiles；MonoDevelop 也不再是現代 Unity 的主要選擇。使用 VS Code 時可在 External Script Editor 指定，但完整的程式分析與除錯仍需要相應的 VS Code 擴充套件。
