ch3_21 message_2（物體間的訊息傳遞介紹）

上一堂只先記住「自己 / 往下 / 往上」。這堂把三種 Message 真的掛到父子階層裡測試，然後再多加一件事：發訊息時可以順便帶一個參數給接收端使用。

SENDMESSAGE · BROADCASTMESSAGE · SENDMESSAGEUPWARDS · PARAMETER

不只喊「做這件事」，還能順便塞一個東西給對方

Message 的第一個重點是「誰聽得到」，第二個重點則是「要執行哪個方法、要不要順便帶一個值」。課程用顏色當參數，讓收到訊息的物件把自己的 Material 顏色改掉。

01測試階層父 / 自己 / 子 02三種方向實測自己 / ↑ / ↓ 03訊息帶參數方法名稱 + 一個值 04接收端怎麼收Color 參數 05完整模型喊給誰 + 喊什麼
01

先擺一棵很單純的父子階層

課程準備三個物件，排成上、中、下三層，再把發訊息的腳本放在中間那層，三個物件都掛上接收訊息的腳本。

上層物件
   │
中間物件  ← 從這裡發訊息
   │
下層物件

ELI5：就像把三個人分別放在樓上、你房間、樓下，然後站在中間測試不同喊法到底誰聽得到。

測試目的把發送者放中間，最容易一次看出「只自己、往上、往下」的差別。
02

三種 Message 實際按一次，規則就固定下來

        上層 ✓
          ↑
          ↑ SendMessageUpwards
          ↑
        中間 ✓  ← 發送者
          ↓
          ↓ BroadcastMessage
          ↓
        下層 ✓

SendMessage
→ 只有中間自己

課程實測結果：

SendMessage
→ 自己

SendMessageUpwards
→ 自己 + 上層父物件

BroadcastMessage
→ 自己 + 下層子物件

而且「同一層附近的其他物件」不會因為離得近就收到 SendMessage。它看的是物件階層與發送方式，不是場景裡誰站得比較近。

方向規則Send = 自己；Upwards = 自己 + ↑；Broadcast = 自己 + ↓。
03

Message 還可以順便帶一個參數

這堂新增的重點是：發訊息時除了指定「要找哪個方法」，還可以附帶一個值，交給接收端的方法使用。

Message(
    "方法名稱",
    一個參數
)

ELI5：不是只大喊「變色！」，而是大喊「變色！」的同時，順手把一盒彩色筆丟過去。

「請執行變色方法」
        +
「這個 Color 拿去用」

課程用不同顏色做示範，讓不同發送方式帶著一個 Color 值一起傳出去。

字幕能確定的範圍

課程明確說明第一個資訊是要呼叫的方法名稱，第二個可以帶一組參數；接收方法的實際名稱在字幕辨識中不清楚，所以這篇不硬寫一個不存在的名稱。

訊息內容第一個重點是「做哪個方法」；第二個可以是「順便把這個值帶過去」。
04

接收端要準備一個「收得下那個值」的方法

課程的接收端方法會接一個 Color 參數。收到 Message 後，方法拿到這個顏色，再把自己的 Material 顏色改掉。

收到訊息
   ↓
找到指定的方法
   ↓
把 Color 參數交進去
   ↓
方法拿 Color 改 Material

五歲版：有人喊你的名字，還丟給你一盒彩色筆。你聽得懂那個指令，也接得到彩色筆，就拿它去把自己塗成指定顏色。

課程最後也提醒，這個 Message 介面在範例中是一組參數；字幕沒有再展開更多參數形式，所以這篇就停在課堂講到的範圍。

接收端方法名稱要對得上，而且參數型別要能接住發送過來的那個值。
05

把 message_1 + message_2 合起來，只要問兩件事

第一題：我要喊給誰？

SendMessage
→ 自己

SendMessageUpwards
→ 自己 + ↑ 父階層

BroadcastMessage
→ 自己 + ↓ 子階層


第二題：我要跟他說什麼？

方法名稱
+
可附帶的一個參數

所以整個流程可以想成：

發送端
「請執行某個方法」
        +
「這個值也拿去」
        ↓
依 Message 類型決定傳給誰
        ↓
接收端找到對應方法
        ↓
把參數交進方法
        ↓
執行自己的行為
這堂核心Message = 指定「誰聽得到」+ 用方法名稱叫它做事 + 可以順便帶一個值。
