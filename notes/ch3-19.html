ch3_19 screen_to_ray（由滑鼠或手機螢幕發射線）

前兩堂的 Ray 都是我們自己準備方向；這堂換成讓玩家用滑鼠或觸控「指一個螢幕位置」，再由 Camera 幫我們把這個 2D 點翻譯成一條射進 3D 世界的 Ray。

MOUSE POSITION · CAMERA · SCREENPOINTTORAY · DEBUG.DRAWRAY

玩家指螢幕哪裡，就從攝影機往那裡打一條 Ray

滑鼠座標本身只是螢幕上的 2D 位置，不能直接告訴我們 3D 世界中的物件在哪。ScreenPointToRay 做的事，就是把「我指著螢幕這裡」翻譯成一條可以拿去做 Raycast 的 3D 射線。

01螢幕座標Input.mousePosition 02轉成 RayScreenPointToRay 03畫出射線Debug.DrawRay 04為什麼不是 3D 點2D 點 → 3D 射線 05怎麼接 Raycast點地板、點怪物 06完整流程螢幕 → Ray → Raycast
01

第一步：先問「玩家現在指著螢幕哪裡？」

Vector3 point = Input.mousePosition;

Input.mousePosition 取得滑鼠在螢幕上的座標。課程也把手機觸控點歸在同一類概念：它們都先是一個「螢幕座標」。

螢幕左下角附近
→ point 大概在左下

滑鼠往右移
→ point 的 x 跟著變大

五歲版：現在只是知道「手指在玻璃上的哪一點」，還不知道玻璃後面的 3D 世界到底指到哪個物件。

Input.mousePosition先回答「玩家在螢幕哪裡指了一下？」
02

ScreenPointToRay：請攝影機把 2D 點翻譯成 3D 射線

Ray ray = Camera.main.ScreenPointToRay(point);

這行是整堂核心。Camera.main 代表主要攝影機，ScreenPointToRay(point) 會根據攝影機與剛才的螢幕位置，算出一條射進 3D 場景的 Ray。

螢幕上的 point
        ↓
Camera.main.ScreenPointToRay(point)
        ↓
Ray
├─ origin    → 從攝影機附近開始
└─ direction → 朝著那個螢幕位置對應的 3D 方向

五歲版：你在窗戶上指一個點，攝影機站在窗戶後面，Unity 幫你畫一條「從攝影機穿過那個點，繼續往世界裡延伸」的線。

ScreenPointToRay把「我指螢幕這裡」翻譯成「從攝影機往這個 3D 方向查」。
03

Debug.DrawRay：把看不見的 Ray 畫給開發者看

Debug.DrawRay(
    ray.origin,
    ray.direction * 1000,
    Color.red
);

課程把射線畫成紅色，長度用 1000。當滑鼠在螢幕上左右移動，Scene 視窗裡的紅線也會跟著改變方向。

滑鼠往左
      ↙
Camera ●────────────→

滑鼠往右
              ↘
Camera ●────────────→
和上一堂一樣

Debug.DrawRay 只是 Scene 裡的除錯視覺，不是玩家真的會在 Game 畫面看到的雷射。

Debug 線只是拿來確認「我現在到底往哪個方向射」。
04

為什麼不是把滑鼠座標直接變成一個 3D 座標？

因為螢幕上的一個點，往攝影機前方延伸時，可以對應很多不同深度的 3D 位置。

螢幕上的同一個點 ●
                    \
Camera ●-------------●------●------●----→
                    近      中      遠

這幾個 3D 點
投影到螢幕上都可能落在同一位置

所以這堂不是：

2D 螢幕點 → 唯一一個 3D 點

而是：

2D 螢幕點 → 一條 3D Ray

接下來再讓 Raycast 去問這條線實際先撞到哪個 Collider，才知道玩家真正點中了什麼。

關鍵差別螢幕點只決定「看出去的方向」，實際點到誰要再靠 Raycast 判斷。
05

接上 Raycast 後，就能做「點哪裡，就處理哪裡」

課程舉了兩種很常見的應用：

點地板
↓
ScreenPointToRay
↓
Raycast 撞到地板
↓
知道玩家點的是世界哪裡
↓
角色移動過去
點怪物
↓
ScreenPointToRay
↓
Raycast 撞到怪物
↓
知道玩家選中了誰
↓
攻擊 / 扣血

也就是說，ScreenPointToRay 不負責判斷「撞到誰」，它只負責生出那條 Ray；真正的命中判斷仍然交給前一堂的 Physics.Raycast。

分工ScreenPointToRay 生出射線；Physics.Raycast 再用射線去找場景裡的目標。
06

三堂 Raycast 串起來，其實是一條完整管線

Raycast_1
→ Ray 是什麼？
→ Origin + Direction

Raycast_2
→ 怎麼真的拿 Ray 去檢查？
→ Physics.Raycast
→ RaycastHit 告訴我撞到誰

screen_to_ray
→ 如果方向來自滑鼠 / 觸控呢？
→ Input.mousePosition
→ Camera.main.ScreenPointToRay
→ 得到 Ray
→ 再交給 Physics.Raycast

這堂的程式本身非常短：

void Update()
{
    Vector3 point = Input.mousePosition;

    Ray ray = Camera.main.ScreenPointToRay(point);

    Debug.DrawRay(
        ray.origin,
        ray.direction * 1000,
        Color.red
    );
}

不要被短程式騙了，它補上的其實是輸入系統和 3D 世界之間非常重要的一座橋。

這堂核心螢幕座標告訴你玩家指哪裡；ScreenPointToRay 把這個 2D 指向翻譯成一條射進 3D 世界的 Ray。
