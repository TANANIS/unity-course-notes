ch1_5 移動、縮放與旋轉

分清楚「移動 Scene 攝影機」與「修改 GameObject Transform」，再掌握工具快捷鍵、Inspector 數值、Pivot／Center 與 Local／Global。

SCENE TOOLS / TRANSFORM / COORDINATES

先判斷你在移動畫面，還是在移動物件

View Tool 只改變開發者觀察 Scene 的角度；Move、Rotate、Scale 才會改變 GameObject。兩種操作都在畫面上動來動去，正好適合拿來折磨初學者。

01

Scene 工具列與快捷鍵

Q — View Tool
平移或旋轉 Scene Camera，只改變編輯器中的觀察視角，不修改任何 GameObject 的 Transform。
W — Move Tool
移動所選 GameObject。拖曳紅、綠、藍軸可沿單一軸移動；拖曳軸之間的小平面可同時改變兩個軸。
E — Rotate Tool
旋轉所選 GameObject。紅、綠、藍圓環分別對應 X、Y、Z 軸。
R — Scale Tool
縮放所選 GameObject。拖曳中央方塊可等比例縮放，拖曳單一軸則只改變該軸。
T — Rect Tool
把移動、縮放與旋轉整合成矩形控制柄，常用於 Sprite、2D 與 UI，也能操作 3D GameObject。
Y — Transform Tool
把 Move、Rotate、Scale 的控制柄整合在同一工具中。Local 模式下還會提供縮放控制柄。
字幕校正

字幕中的「W 是位移、旋轉、R 是說話、T 是二 D 平面縮放」應重建為：W 移動、E 旋轉、R 縮放、T Rect、Y Transform。自動字幕不是筆記，只是術語遭遇車禍後留下的現場紀錄。

02

Inspector 中的 Transform

Position
物件在 X、Y、Z 軸的位置。沒有父物件時通常以世界座標表示；有父物件時 Inspector 顯示的是相對於父物件的 Local Position。
Rotation
物件繞 X、Y、Z 軸旋轉的角度，Inspector 以度數顯示。Unity 內部的旋轉儲存不等於單純三個角度，因此之後寫程式時不能只把它當普通 Vector3。
Scale
沿 X、Y、Z 軸的縮放倍率。1, 1, 1 代表原始比例；三軸不同就是非等比例縮放。
Constrained Proportions
Scale 左側的連結圖示。啟用後，修改一個軸會依目前比例連動其他軸。
軸向顏色 X 是紅色、Y 是綠色、Z 是藍色。Unity 世界中正 X 向右、正 Y 向上、正 Z 向前。
Reset 不一定回到世界原點

在 Transform 標題列的內容選單選擇 Reset，會把 Local Position 設為 0,0,0、Local Rotation 設為 0,0,0、Local Scale 設為 1,1,1。若物件有 Parent，它會回到父物件的座標原點，不一定是整個 Scene 的世界原點。

03

移動 Scene Camera，不修改 GameObject

平移 Pan
按住滑鼠中鍵拖曳；選擇 View Tool 後也可直接拖曳 Scene 畫面。
環繞 Orbit
按住 Alt 再以滑鼠左鍵拖曳，繞目前軸心旋轉 Scene Camera。2D 模式下不可用。
縮放 Zoom
使用滑鼠滾輪，或按住 Alt 加滑鼠右鍵拖曳。
Flythrough
按住滑鼠右鍵後，用滑鼠改變觀看方向，並以 WASD 前後左右移動、Q/E 上下移動。
速度
Flythrough 中按住 Shift 可加速；移動時使用滾輪可調整 Scene Camera 的飛行速度。
F
選取 GameObject 後把滑鼠移到 Scene 視窗並按 F，可將視角聚焦到所選物件。
字幕中的「LT」其實是 Alt

正確操作是 Alt + 左鍵 環繞，而不是某個神祕的 LT 鍵。字幕也把 WASD 拆成了「wsdao」，足以證明語音辨識有時只是很自信地猜字。

04

Pivot 與 Center：決定控制柄放在哪裡

Pivot
把 Transform Gizmo 放在 GameObject 實際的軸心點，也就是 Transform 所定義的原點。
Center
把 Gizmo 放在依目前選取物件計算出的中心位置；多選物件時通常能得到整組選取範圍的中心。
「自轉／公轉」只是操作結果的比喻

老師用自轉與公轉說明多選旋轉，直覺上能理解，但核心概念不是天文學：Pivot／Center 控制的是 Gizmo 的位置。控制柄位置改變後，旋轉或縮放的結果才可能看起來像各自旋轉或繞共同中心旋轉。

05

Local 與 Global：決定控制柄朝哪個方向

Local
Gizmo 的軸向跟著物件自身的旋轉。物件轉向後，它的紅、綠、藍軸也會一起轉。
Global
Gizmo 固定對齊世界座標。無論物件自身怎麼旋轉，控制柄仍維持世界 X、Y、Z 的方向。
世界座標
整個 Scene 共用的固定座標系，可參考 Scene 視窗右上角的方向覆蓋層。
本地座標
以物件自身方向與 Parent Transform 為基準的座標系，適合表達「往物件自己的前方移動」。
一句話記憶 Pivot／Center 管 Gizmo 放哪裡；Local／Global 管 Gizmo 朝哪裡。前者是位置，後者是方向。
不要把 Local／Global 誤解成修改 Transform 數值模式

這個切換主要控制 Scene Gizmo 的方向，不會把 Inspector 裡的 Position 欄位直接改成「世界座標顯示器」。有 Parent 時，Inspector 的 Transform 數值仍主要是相對父物件的局部值。

左手座標系

Unity 使用左手座標系：正 X 向右、正 Y 向上、正 Z 向前。字幕中「立軸」「Vocal」「LOGO」分別是在誤認 Z 軸、Local、Global，不要把這些幽靈術語抄進腦袋。
