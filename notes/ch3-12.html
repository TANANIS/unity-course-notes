ch3_12 Transform_2（Transform 物件常用方法介紹）

這堂用 TestTransform1 把上一堂的 Transform API 一個個跑過。重點是比較「直接設定狀態」與「持續累加變化」，並實際觀察 Local / World 方向、Euler Angle、Quaternion 與 LookAt。

POSITION · TRANSLATE · LOCAL / WORLD · ROTATION

同樣是移動或旋轉，API 的語意可能完全不同

這堂不要只看「物件動了」，而要分辨它是被指定到某個狀態，還是在目前狀態上持續增加。

01測試設定euler 與 move 02position / Translate指定位置 vs. 累加位移 03TransformDirectionLocal / World 實際差異 04Quaternion / Euler旋轉表示與 Rotate 05LookAt持續朝向 target
01

TestTransform1 的共用測試資料

public Transform target;

Vector3 euler = new Vector3(0, 270, 0);
Vector3 move = Vector3.forward * 5;

euler 代表繞 Y 軸 270 度；move 等於 (0, 0, 5)，代表 +Z 方向 5 單位。後面每個測試都用這兩個向量觀察 Transform 的不同 API。

測試基準euler = Y 270°；move = +Z 5。
02

position 是直接指定；Translate 是在目前位置上增加

void testPosition()
{
    transform.position = move;
}

這段執行後，物件的位置直接變成 (0, 0, 5)。課程用「往前五格」描述結果，但程式語意是把世界座標設定成這個值。

void testTranslate()
{
    transform.Translate(move * Time.deltaTime);
}

Translate() 則會在目前位置基礎上持續增加位移。因為 move 長度是 5，並乘上 Time.deltaTime，課程觀察到物件持續以每秒約 5 單位向前移動。

position = ...
→ 直接設定目前位置

Translate(...)
→ 從目前位置再移多少
最重要對照position 是狀態指定；Translate 是位移累加。
03

TransformDirection：角色自己的前方，換算成世界中的方向

物件沒有旋轉時，Local forward 和 World 的 +Z 看起來可能一樣；真正的差異要等物件旋轉後才明顯。

課程用東南西北比喻 World 與 Local：

World / Global
→ 東方永遠是東方
→ 不會因為物件轉身而改變

Local
→ 物件自己的前方
→ 物件旋轉後，前方也跟著旋轉

因此當物件已經轉向，而移動又希望跟著「自身前方」時，可以把本地方向轉成世界方向：

Vector3 worldDirection =
    transform.TransformDirection(Vector3.forward);
建立直覺

Vector3.forward 先表示「Local 的前方」，TransformDirection 再回答「這個前方放到世界座標到底是哪邊」。

Local / World世界方向不因物件旋轉改變；本地方向會跟著物件朝向改變。
04

Euler Angle 與 Quaternion，以及設定旋轉與累加旋轉

課程先用容易理解的 Vector3 表示想要的旋轉：

Vector3 euler = new Vector3(0, 270, 0);

若要指定 transform.rotation，則用 Quaternion.Euler() 將 Euler Angle 轉成 Quaternion：

transform.rotation = Quaternion.Euler(euler);

也可以直接以 Euler Angle 形式設定：

transform.eulerAngles = euler;

兩者都可表達 Y 軸 270 度的旋轉，只是資料表示不同。課程特別強調 Quaternion 的四個數值不容易直接看出軸向與角度，因此 Euler Angle 對人比較直觀。

Rotate() 則不是指定到固定角度，而是在目前旋轉上繼續增加：

transform.Rotate(euler * Time.deltaTime);

乘上 Time.deltaTime 後，課程把 270 理解為每秒旋轉約 270 度；如果不乘 deltaTime，就會變成每個 Frame 都累加 270 度。

rotation / eulerAngles
→ 設定目前旋轉

Rotate(...)
→ 持續增加旋轉
旋轉模型Euler 適合人理解；Quaternion 是 rotation 使用的表示方式；Rotate 負責累加。
05

LookAt：讓物件持續看向 target

課程先透過 Inspector 指定 public Transform target，之後把目標的位置傳進 LookAt：

transform.LookAt(target.position);

執行後，當 target 移到物件周圍不同位置，測試物件會跟著旋轉，維持面向 target。

target.position
      ↓
   LookAt()
      ↓
更新自己的 rotation

這種方法可建立「某物件持續面向另一個物件」的基本行為。

這堂核心先分清楚「指定狀態」與「累加變化」，再處理 Local / World，Transform API 就不容易混。
