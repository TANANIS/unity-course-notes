ch3_5 Vector_3（向量類介紹）

這堂把向量直接拿來做移動：使用 Vector3.MoveTowards，讓物件在 Update() 中以指定速度持續靠近目標點，而且抵達時不會越過目標。

MOVETOWARDS · DELTATIME · SPEED

現在在哪裡、要去哪裡、這次最多走多遠

MoveTowards 的三個參數就是整堂課的骨架。再搭配 Time.deltaTime * speed，把「每秒速度」換算成「這一幀應該走的距離」。

01MoveTowards三個參數 02每幀距離deltaTime × speed 03為什麼放 Update持續重新計算 04不會越過目標抵達就停 05向量乘數字方向不變、長度縮放 06補充理解MoveTowards 不是 easing
01

MoveTowards：從目前位置往目標靠近

Vector3.MoveTowards(current, target, maxDistanceDelta)
current
目前位置，也就是「我現在在哪裡」。
target
目標位置，也就是「我要去哪裡」。
maxDistanceDelta
這一次呼叫最多可以前進多少距離。

老師的範例先取得物件目前的位置，再把 MoveTowards 算出的新位置指定回 transform.position：

Vector3 currentPoint = transform.position;

transform.position = Vector3.MoveTowards(
    currentPoint,
    targetPoint,
    maxDistanceDelta
);
一句話翻譯從 current 朝 target 前進，但這一次最多只走 maxDistanceDelta。
02

Time.deltaTime × speed：這一幀應該走多遠

老師用公開的 speed 表示每秒希望移動多少 Unity 單位，再乘上 Time.deltaTime，換算成本幀應移動的距離：

public int speed = 3;

float maxDistanceDelta = Time.deltaTime * speed;
speed
= 每秒想走多少單位

Time.deltaTime
= 這一幀經過多少秒

speed × Time.deltaTime
= 這一幀應該移動多少距離

例如 speed = 3，某幀的 deltaTime = 0.02 秒，那一幀最多前進 0.06 單位。

先知道用途即可

Time.deltaTime 會在接下來的 Time 課程正式介紹。這堂先把它理解成「讓每秒速度換算成每幀距離」即可。

03

為什麼一定放在 Update？因為一次 MoveTowards 只算一步

老師把移動放在 Update()，讓 Unity 每一幀重新取得現在位置、重新計算本幀距離，再往目標走一步。

void Update()
{
    Vector3 currentPoint = transform.position;
    float maxDistanceDelta = Time.deltaTime * speed;

    transform.position = Vector3.MoveTowards(
        currentPoint,
        targetPoint,
        maxDistanceDelta
    );
}
取得目前位置
↓
算這幀能走多少
↓
往目標前進一點
↓
下一幀重新計算
↓
持續到抵達目標

如果只在 Start() 呼叫一次，它只會前進一次，不會自己一路跑完整段路。

Update 的角色不是 MoveTowards 自己會持續移動，而是 Update 每幀一直重新呼叫它。
04

MoveTowards 不會越過目標

老師特別強調：當剩餘距離比 maxDistanceDelta 還短時，MoveTowards 會直接回傳目標位置，而不是多走一步衝過頭。

目前 ● -------- ★ 目標

剩餘距離：0.2
本幀最多可走：0.5

結果：直接停在 ★
不是跑到 ★ 後面。

因此它很適合「角色點擊地面後走到指定點」、「NPC 前往指定位置」、「物件回到原位」這類明確目標點移動。

抵達規則一路靠近，最後精確停在 target，不會 overshoot。
05

向量乘上一個數字：方向不變，長度跟著縮放

講義最後補了一個基本向量運算：

Vector3 v = new Vector3(2, 3, 5);
v *= 2;

// v = (4, 6, 10)

每個軸一起乘上 2。接回前面「向量是一支箭」的心智模型，就是箭頭方向不變、長度變成兩倍。

Vector3.forward * 5
// (0, 0, 5)
// 仍然朝前，只是長度從 1 變成 5

這也能和 normalized 串起來：

Vector3 direction = someVector.normalized;
Vector3 velocity = direction * speed;

// 純方向 × 想要的速度
純量乘法向量 × 數字 = 保留方向，縮放整支向量的長度。
06

補充理解：MoveTowards 的「平順」不是 easing

這一段是課後補充。講義把 MoveTowards 描述成平順移動，但不要把它理解成自動加速、減速的動畫曲線。若 speed 固定，它基本上就是固定速度靠近，抵達後停止。

固定速度 → 固定速度 → 固定速度 → 抵達 → 停

後面課程會另外介紹 Lerp。兩者不要現在混成同一個概念。
