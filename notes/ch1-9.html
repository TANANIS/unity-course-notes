ch1_9 Prefabs

把設定好的 GameObject 做成可重複使用的 Prefab Asset，再從它建立多個能集中維護的場景 Instance。

PREFAB ASSET / INSTANCE

先做一個範本，再重複使用

當敵人、道具、子彈或場景物件會大量重複出現時，不必逐個重新設定。Prefab 把 GameObject 的階層、Component、材質與其他設定保存成 Project 裡的範本。

01Prefab 概念Asset 與 Instance 02建立 PrefabHierarchy 拖到 Project 03同步修改材質與子物件 04OverridesApply 與個別差異 05效能校正Prefab 不等於零成本
01

Prefab 是 GameObject 的可重複使用範本

Prefab Asset
儲存在 Project 裡的範本，保存 GameObject 的階層、Component、材質與設定。
Prefab Instance
把 Prefab Asset 拖進 Scene 後建立的場景實例。多個 Instance 可以共用同一份 Prefab 設定。
常見用途
敵人、道具、子彈、特效、可互動物件與重複使用的 UI 元件。
程式生成
之後可透過 Instantiate 在執行期間動態建立 Prefab Instance。
一句話記憶Prefab Asset 是範本；Scene 裡的是 Prefab Instance。
02

建立與使用 Prefab

  1. 01
    先設定 GameObject

    在 Scene／Hierarchy 建立 Cube，調整需要的 Component、材質與子物件。

  2. 02
    拖到 Project

    把 Hierarchy 裡的 Cube 拖到 Project 資料夾，Unity 會建立 Prefab Asset。

  3. 03
    建立多個 Instance

    把 Project 裡的 Prefab 多次拖回 Scene，即可建立多個 Prefab Instance。

  4. 04
    辨認 Prefab 關係

    Prefab Asset 與其場景 Instance 通常會以藍色圖示或藍色名稱標示。

老師刪除原 Cube 的原因

刪除原本場景中的 Cube，只是為了讓後續練習都使用從 Prefab 建立的 Instance，避免把普通 GameObject 和 Prefab Instance 混在一起。

03

修改 Prefab，集中更新多個 Instance

修改材質
建立黃色 Material 並套到 Prefab Asset 後，未覆寫材質的場景 Instance 會一起更新。
新增子物件
在 Prefab 中加入 Sphere 子物件後，其他使用同一 Prefab 的 Instance 也會得到相同階層。
Prefab Mode
可雙擊 Project 裡的 Prefab Asset，進入 Prefab Mode，直接編輯範本內容。
主要價值只維護一份範本，就能同步大量重複物件的共同設定。
04

Instance Override、Apply 與 Revert

場景中的 Prefab Instance 可以暫時擁有和 Prefab Asset 不同的設定，這些差異稱為 Override。

Override
只修改目前這一個 Instance。例如單獨改變位置、材質、Component 數值或新增子物件。
Apply
把 Instance 的修改寫回 Prefab Asset。老師字幕裡辨識成「Play」的地方，實際概念應是 Apply。
Revert
捨棄目前 Instance 的 Override，恢復成 Prefab Asset 的設定。
不是所有 Instance 都無條件同步

修改 Prefab Asset 時，通常只有沒有針對該項目建立 Override 的 Instance 會跟著更新。某個 Instance 若單獨覆寫材質，它可能繼續保留自己的材質。

05

Prefab 的主要價值不是自動節省所有記憶體

Prefab 能讓多個物件引用相同的 Mesh、Material、Texture 等 Asset，也能避免把相同設定人工複製到處。但每個生成出的 GameObject Instance 仍然需要自己的 Transform、Component 與執行狀態。

真正的優點
重複使用結構、批次維護、保持設定一致，以及方便透過程式動態生成。
不是免費複製
大量 Prefab Instance 仍會消耗 CPU 與記憶體；敵人很多時，之後還可能需要物件池、LOD 或其他效能策略。
完整結論Prefab 解決的是重複建置與集中維護，不是讓每個 Instance 變成零成本幻影。
