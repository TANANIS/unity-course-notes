ch3_13 Quaternion（四元數常用方法介紹）

這堂先不要管四元數的數學。先把它想成：Unity 用來表示「物件現在朝哪裡」的一種旋轉資料。這堂真正要做的事只有一件：讓物件慢慢把頭轉向目標。

QUATERNION · LOOKROTATION · ROTATETOWARDS · DIRECTION

先知道「朋友在哪」，再慢慢把頭轉過去

可以把整堂想成：你站在原地，朋友站在旁邊。先算出朋友在哪個方向，再算出頭要轉成什麼方向，最後不要瞬間甩頭，而是一點一點轉過去。

01

Quaternion 先想成「物件朝哪裡」的資料

這堂不需要先理解四元數背後的數學。對現在來說，只要知道：

position  → 物件在哪裡
rotation  → 物件朝哪裡
Quaternion → Unity 常用來表示 rotation 的方式

所以看到 Quaternion 時先不要緊張。把它當成一張「方向小紙條」就好，上面寫著物件應該朝哪裡。

一句話記憶Quaternion = Unity 用來表示旋轉方向的一種資料。
02

第一步：朋友到底在哪個方向？

Vector3 direction = target.position - transform.position;

target.position 是朋友站的位置，transform.position 是自己站的位置。

所以「朋友的位置 - 我的位置」就會得到一支箭頭，從我這裡指向朋友：

我 ●--------------------→ ● 朋友
          direction

五歲版：你不用知道朋友的完整地址，你只要知道「他在我右邊那邊」。這個 direction 就是在回答這件事。

方向公式目標位置 - 自己位置 = 從自己指向目標的方向。
03

LookRotation：告訴我「頭應該轉成哪裡」

Quaternion lookAtQuaternion =
    Quaternion.LookRotation(direction);

LookRotation() 不會直接幫物件轉頭。它只是看著剛才那支方向箭頭，幫你算出：

「如果我要看著這個方向，rotation 應該長什麼樣？」

可以想成你用手指著朋友，然後問 Unity：「如果我要面向他，我的頭要轉成什麼方向？」Unity 算完後，把答案裝進一個 Quaternion 給你。

direction
    ↓
Quaternion.LookRotation(direction)
    ↓
「應該朝這裡」的 Quaternion
LookRotation它負責算答案，不負責真的把 Transform 轉過去。
04

RotateTowards：不要瞬間甩頭，每次只轉一點

transform.rotation = Quaternion.RotateTowards(
    transform.rotation,
    lookAtQuaternion,
    20 * Time.deltaTime
);

這三個參數可以直接翻成人話：

transform.rotation
→ 我現在頭朝哪裡

lookAtQuaternion
→ 我最後想朝哪裡

20 * Time.deltaTime
→ 這一幀最多准我轉多少

因為這行放在 Update() 裡每幀執行，所以物件會一點一點轉向目標，而不是瞬間跳到目標旋轉。

課程使用 20 * Time.deltaTime，可以理解成每秒最多大約旋轉 20 度。數字調大，就會更快轉過去。

概念校正

第三個參數不是「延遲多久才轉」，而是這一次呼叫最多能旋轉多少角度。搭配 Time.deltaTime，才形成容易理解的每秒旋轉速度。

RotateTowards現在方向 → 目標方向，但每一幀只准靠近一點。
05

完整程式：一行一行翻成人話

課程範例的欄位名稱寫成 tager；筆記統一整理成較清楚的 target。

public Transform target;

void Update()
{
    TestLookRotation();
}

void TestLookRotation()
{
    Vector3 direction = target.position - transform.position;

    Quaternion lookAtQuaternion =
        Quaternion.LookRotation(direction);

    transform.rotation = Quaternion.RotateTowards(
        transform.rotation,
        lookAtQuaternion,
        20 * Time.deltaTime
    );
}
public Transform target;
→ 我要看誰？

目标位置 - 自己位置
→ 他在我哪個方向？

LookRotation(direction)
→ 如果我要看他，我應該朝哪裡？

RotateTowards(...)
→ 不要瞬間轉，每幀慢慢轉一點。

所以整堂其實只是這個流程：

朋友在哪？
   ↓
算出方向
   ↓
算出該轉成什麼方向
   ↓
每幀慢慢轉過去
這堂核心LookRotation 負責「我要朝哪裡」；RotateTowards 負責「我要多快轉過去」。
06

和上一堂 LookAt 的差別：直接看，還是自己控制轉頭速度

transform.LookAt(target);
→ 直接讓物件面向目標

Quaternion.LookRotation(direction)
+ Quaternion.RotateTowards(...)
→ 先算目標旋轉，再自己控制怎麼轉過去

五歲版：

LookAt
→「看他！」然後直接把頭轉過去。

LookRotation + RotateTowards
→「他在那裡，慢慢把頭轉過去。」

因此這堂的寫法多了一層控制，比較適合需要平滑轉向的行為，例如敵人、砲塔或角色逐漸面向目標。

LookAt vs. QuaternionLookAt 比較直接；拆成 LookRotation + RotateTowards 就能控制轉向過程。
