ch2_4 邏輯判斷式

前一堂已經能用比較運算得到 true / false；這堂把結果放進 if、else if、else，讓程式依條件選擇不同動作。

CONDITIONAL BRANCHING

如果條件成立，就做對應的事情

條件判斷的核心很直接：先檢查條件，成立就執行指定區塊；不成立時，可以交給下一個條件或最後的 else。

01if / else成立與否兩條路 02else if多個條件 03區間判斷比較 + && 04遊戲用途HP 對應不同狀態
01

最基本的 if / else

int hp = 100;

if (hp > 0)
{
    Debug.Log("角色還活著");
}
else
{
    Debug.Log("角色死亡");
}
if (...)
小括號內放條件；條件成立時執行大括號內的程式。
else
當前面的條件不成立時，改執行這個區塊。
一句話記憶if 問「是不是？」；成立走 if，不成立走 else。
02

條件不只兩種：else if

如果狀態有多個區間，可以在 if 和最後的 else 之間加入多個 else if。

if (/* 條件 A */)
{
    // A 成立時執行
}
else if (/* 條件 B */)
{
    // B 成立時執行
}
else
{
    // 前面條件都不符合
}

老師用角色 HP 分級示範：不同血量區間可以觸發不同攻擊或狀態。

03

用比較運算與 && 判斷數值區間

要判斷 HP 是否落在某個範圍，需要同時滿足上下界，因此會把上一堂的比較運算與 && 組合起來。

if (hp <= 100 && hp >= 70)
{
    Debug.Log("一般攻擊");
}
else if (hp <= 69 && hp >= 40)
{
    Debug.Log("強力攻擊");
}
else if (hp <= 39 && hp >= 1)
{
    Debug.Log("可以放大招");
}
else
{
    Debug.Log("無效");
}
70 ～ 100
一般攻擊。
40 ～ 69
強力攻擊。
1 ～ 39
可以放大招。
其他
落到最後的 else，老師示範為無效狀態。
04

遊戲裡很常拿條件分支控制狀態

老師舉的例子包括：角色是否還活著、低血量時改變可用攻擊、觸發動畫或事件，以及進入下一個關卡等。

如果只是簡單的兩種狀態，if / else 就足夠；如果需要判斷多個條件或數值區間，就可以加入 else if。

本堂結論比較運算產生條件，if / else if / else 則根據條件決定程式要走哪一條路。
