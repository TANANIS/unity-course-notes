ch1_3 Unity3D 建立物件與父子關係

先認識 GameObject → 3D Object 裡能建立的物件，再理解哪些只是測試用幾何體，哪些其實是完整系統的入口。

3D OBJECT MENU

這份選單不是「各種形狀大全」

Cube 到 Quad 是基本幾何體；Text、Ragdoll、Terrain、Tree、Wind Zone 則分別屬於文字、角色物理與地形植被系統。Unity 把它們塞進同一個選單，只能說分類學再次敗給了方便。

01

建立方式

可從上方選單 GameObject → 3D Object，或在 Hierarchy 空白處按右鍵後選擇 3D Object。

02

基本幾何體 Primitive

Cube 方體
六面立方體。最常拿來快速搭牆、地板、平台、障礙物與碰撞區，是灰盒原型的主力。
Sphere 球體
球形物件。適合球、行星、範圍提示或測試滾動物理。預設碰撞器為 Sphere Collider。
Capsule 膠囊體
中間是圓柱、上下為半球。形狀接近站立角色，常用來暫代玩家或敵人，也適合作為角色碰撞體。
Cylinder 圓柱體
上下平面、側面為圓弧。適合柱子、桶子、輪軸與圓形平台。注意預設通常使用 Mesh Collider，不一定適合直接拿來做大量動態物理。
Plane 平面
由多個網格面組成的大型水平面，預設尺寸約為 10×10 Unity 單位。常作為測試地面，也方便之後做網格細分或頂點變形。
Quad 四邊面
只有一個矩形面，預設面向本地 Z 軸。適合 3D 場景中的圖片、告示牌、特效面片與簡單背景。
Plane 不等於 Quad

Plane 是水平、較大且有多個網格分段的地面；Quad 是單一四邊形面片。兩者看起來都扁，不代表用途相同，紙和磁磚也都扁，文明仍勉強把它們分開。

03

建立後通常會有哪些 Component？

Transform
位置、旋轉、縮放與父子階層。所有 GameObject 都一定有。
Mesh Filter
指定物件使用哪個 Mesh，也就是實際的幾何形狀資料。
Mesh Renderer
負責把 Mesh 畫到畫面上，並使用指定的 Material。
Collider
提供碰撞形狀。Cube、Sphere、Capsule 等會依形狀附上對應 Collider。
一句話記憶Mesh Filter 決定長什麼形狀，Mesh Renderer 決定怎麼被畫出來，Collider 決定怎麼碰撞。
04

其他 3D Object 項目

Text - TextMeshPro
在 3D 世界中建立 TextMeshPro 文字。文字存在場景座標裡，不是一般 Canvas UI；適合角色頭頂名稱、世界內標示與立體字幕。
Legacy
舊版 3D Text 等相容功能。新專案通常優先使用 TextMeshPro，除非正在維護舊內容。
Ragdoll...
開啟 Ragdoll Wizard，替已建立骨架的角色配置 Rigidbody、Collider 與 Character Joint，讓角色死亡或失去控制時產生布娃娃物理。它不是一按就憑空生出人體。
Terrain
建立 Unity Terrain 地形，可雕刻高度、繪製地表材質並放置草與樹。適合戶外大型地面，不是普通 Plane 的華麗皮膚。
Tree
建立 Tree Editor 使用的樹木資產／物件，可配置樹幹與枝葉，之後可放進 Terrain。是否出現或推薦使用，會受 Unity 版本與渲染流程影響。
Wind Zone
建立風力區域，主要影響支援風擺動的樹木、植被與部分粒子效果。它不會自動把場景裡所有 Rigidbody 吹走。
05

父子關係的起點

把一個 GameObject 在 Hierarchy 中拖到另一個 GameObject 下方，就會建立 Parent / Child 關係。子物件的 Transform 會改以父物件作為座標參考。

父物件移動
子物件會跟著移動。
父物件旋轉
子物件會繞著父物件的 Transform 一起旋轉。
父物件縮放
子物件的世界尺寸通常也會受到影響。
Local Position
子物件相對於父物件的位置，不是相對於整個世界原點。
不要把父子關係當資料夾

Hierarchy 確實能用來整理，但 Parent / Child 會實際改變 Transform 的計算。若只想分類物件，通常建立 Empty GameObject 當群組，並留意其位置、旋轉與縮放是否乾淨。
