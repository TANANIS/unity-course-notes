ch2_11 物件

上一堂先定義了類別（class）；這堂開始真的用類別建立物件（object）。同一個類別可以建立很多個物件，而每個物件都能保存自己的攻擊力、血量、等級等狀態。

OBJECT

Class 是規格；Object 是照規格建立出的實體

先有類別，才能用它建立物件。同一類別建立出的不同物件共享相同的結構，但各自保存不同的資料。

01

先有類別，才會有物件

老師先把上一堂與這堂接起來：物件和類別息息相關，必須透過類別去建立物件。

為什麼不能只有一個「怪物」類別就結束？因為遊戲裡每一隻怪物雖然都屬於怪物這個類別，但實際狀態不一定相同。

同一類別
怪物都可以擁有攻擊力、血量、技能等共同結構。
不同物件
每隻怪物目前的血量、攻擊力或技能內容可以不同。
原因
例如其中一隻怪物已經被玩家攻擊，另一隻還是滿血；它們仍然都屬於「怪物」這個類別。
一句話記憶Class 定義共同結構；Object 保存某一個實體自己的狀態。
02

用類別建立一個物件

課堂延續上一堂的 Weapon 類別，再到另一個繼承 MonoBehaviour 的測試腳本裡建立武器物件。

字幕中的程式名稱有辨識缺漏，下面用等價寫法整理課堂操作：

Weapon kingSword = new Weapon();
Weapon
型別，也就是上一堂建立的類別。
kingSword
變數名稱，用來指向這個建立出來的 Weapon 物件。
new Weapon()
依照 Weapon 類別建立一個新的物件。
和 int 的宣告很像，但右邊不一樣

可以把 Weapon kingSword 類比成 int hp：左邊先說明型別與變數名稱。不同的是 Weapon 需要的是一個 Weapon 物件，所以右側用 new Weapon() 建立實體。

03

要從其他類別存取成員，課堂先使用 public

老師建立 Weapon 後，嘗試從另一個測試類別設定武器資料，發現原本的成員無法直接存取，因此把它們加上 public。

public class Weapon
{
    public float attackPower;
    public float wear;
    public int levelLimit;
}

接著就可以透過「物件名稱 + . + 成員」設定資料：

kingSword.attackPower = 100;
kingSword.wear = 10;
kingSword.levelLimit = 50;
老師自己也提醒：先別把 public 當最佳做法

這堂為了說明跨類別存取，暫時直接把資料成員設成 public。老師隨即提醒，實務上通常不希望資料欄位毫無限制地公開；後面的「封裝」會再解釋原因與做法。

04

同一個 Weapon 類別，可以有很多把不同的武器

老師接著建立第二把武器。兩把都屬於 Weapon，但各自保存自己的資料。

Weapon kingSword = new Weapon();
kingSword.attackPower = 100;
kingSword.wear = 10;
kingSword.levelLimit = 50;

Weapon battleAxe = new Weapon();
battleAxe.attackPower = 600;
battleAxe.wear = 2;
battleAxe.levelLimit = 90;

執行時分別印出兩把武器的攻擊力，就會得到不同結果：

Debug.Log(kingSword.attackPower); // 100
Debug.Log(battleAxe.attackPower); // 600

這正是物件存在的理由：結構由 Weapon 類別統一定義，但每一個 Weapon 物件可以保存不同的攻擊力、磨損程度與等級限制。

核心觀念同一類別 ≠ 所有資料都一樣。類別決定「有哪些欄位」；物件決定「這一個實體的欄位目前是多少」。
05

直覺版：Class 是藍圖，Object 是照藍圖做出的成品

Weapon 類別（藍圖）
├── attackPower
├── wear
└── levelLimit

        ↓ new Weapon()

王者之劍（物件）
├── attackPower = 100
├── wear = 10
└── levelLimit = 50

戰斧（物件）
├── attackPower = 600
├── wear = 2
└── levelLimit = 90

藍圖只有一份也沒關係，可以照同一份藍圖做出很多成品。成品的結構相同，但每一個成品的實際數值可以不同。

遊戲為什麼特別需要物件導向？

老師最後用遊戲中的大量裝備、怪物與角色作為例子。這些東西通常有共同的資料結構，但每一個實體又有自己的狀態，因此很適合用類別與物件來表示。

本堂結論class 是規格；new 建立 object；同一類別建立出的每個物件，都可以保存自己獨立的資料。
