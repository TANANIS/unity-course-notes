ch2_3 比較

比較運算會拿兩個值進行判斷，最後得到 true 或 false。之後寫條件分支時，這些結果就是決定程式要不要執行某段邏輯的基礎。

COMPARISON OPERATORS

比較的結果是 bool

不論是判斷兩個值是否相等，還是誰大誰小，比較運算最後都會產生布林值。

01相等與不等== / != 02大小比較> / < 03包含等於>= / <= 04遊戲中的用途狀態與條件判斷
01

相等與不相等

int value1 = 10;
int value2 = 30;

bool isEqual = value1 == value2;      // false
bool isNotEqual = value1 != value2;   // true
==
判斷左右兩邊是否相等。
!=
判斷左右兩邊是否不相等。
別和賦值混在一起

= 是把值指定給變數；== 才是比較兩邊是否相等。

02

大於與小於

bool isGreater = value1 > value2;   // false
bool isLess = value1 < value2;      // true
>
左邊是否大於右邊。
<
左邊是否小於右邊。
03

大於等於與小於等於

bool atLeast = value1 >= value2;
bool atMost = value1 <= value2;
>=
只要「大於」或「等於」其中一種成立，結果就是 true。
<=
只要「小於」或「等於」其中一種成立，結果就是 true。
一句話記憶>、< 不包含相等；>=、<= 把相等也算進去。
04

比較通常用來建立條件

老師提到，遊戲裡常會需要判斷角色目前的數值或狀態是否達到某個條件，再決定接下來要做什麼。

bool isLowHp = hp <= 20;
bool canLevelUp = exp >= requiredExp;
bool isDead = hp == 0;

這一堂先只處理「比較得到 bool」。下一堂會把這些比較結果放進條件分支，真正決定程式執行哪一段。

本堂結論比較運算不是算出新的數字，而是在回答一個問題：這個條件成立嗎？
