ch3_18 Raycast_2（射線用法介紹）

上一堂只認識「雷射筆有哪些零件」，這堂真的把它射出去：先算世界方向、建立 Ray、用 Debug 畫出來，再讓 Physics.Raycast 回答「到底有沒有撞到、撞到誰」。

RAY · DEBUG.DRAWRAY · RAYCASTHIT · OUT · LAYERMASK

把雷射筆射出去，再把撞到的答案拿回來

整堂可以想成探路：先準備起點和方向，派出一條看不見的探測線，如果撞到東西，就把命中資訊塞進 RaycastHit，接著程式再決定要做什麼。

01世界方向TransformDirection 02建立 RayOrigin + Direction 03畫出 Debug 線只給開發者看 04RaycastHit + out把命中答案帶回來 05命中後做事情變藍、離開變紅 06LayerMask只理指定 Layer 07完整流程一次串起來
01

先把「我的前方」換成世界真正的方向

Vector3 forward = transform.TransformDirection(Vector3.forward);

Vector3.forward 可以先理解成「物件自己的前方」。但物件可能已經轉過身，所以課程用 TransformDirection() 把 Local 方向轉成 World 方向。

物件自己說：
「往我的前面射！」

Unity 需要知道：
「你現在轉過之後，世界裡的前面到底是哪邊？」

TransformDirection
→ Local 方向換成 World 方向
世界方向先把「我的前方」翻譯成「世界裡真正往哪邊」。
02

建立 Ray：從自己位置，往剛算好的方向射

Ray ray = new Ray(
    transform.position,
    forward
);

這正好接回上一堂：

Ray
├─ origin    = transform.position
└─ direction = forward

五歲版：拿一張小紙條寫下「從我現在站的位置開始，往這個方向照」。

RayRay 只描述「從哪裡、往哪裡」，還沒有真的做物理檢查。
03

Debug.DrawRay：先讓自己看見那條本來看不見的線

Debug.DrawRay(
    ray.origin,
    ray.direction * distance,
    Color.blue
);

Raycast 本身是看不見的，所以課程先用藍色 Debug 線幫開發者確認方向。

ray.direction
→ 只有方向：→

ray.direction * distance
→ 方向乘上長度：────────────────→

課程設定 distance = 100，因此 Debug 線大約畫到 100 的距離。

注意

Debug.DrawRay 是除錯工具，不是遊戲裡真正可見的雷射特效。課程也明確把真正畫線的效果留到後面的 Line Renderer。

Debug.DrawRay只是開發者的螢光筆，用來確認射線到底往哪裡。
04

RaycastHit：探測線撞到東西後帶回來的小紙條

RaycastHit hit;

在射出去以前，我們根本不知道會碰到誰，所以先準備一個空的 hit，等 Physics.Raycast 執行後再把答案塞進去。

if (Physics.Raycast(ray, out hit, distance))
{
    ...
}

把它翻成人話：

Physics.Raycast(
    ray,         → 把哪條射線射出去？
    out hit,     → 撞到的答案幫我塞進 hit
    distance     → 最遠找多遠？
)

Physics.Raycast(...) 本身還會回傳 bool：

true  → 有撞到
false → 沒撞到

這也正是前面 C# 學過的 out 真正派上用場的地方：方法執行時負責把結果寫回變數。

Ray vs. RaycastHitRay 是「我要往哪查」；RaycastHit 是「查完撞到什麼」。
05

射到東西後，就可以拿 hit 找到那個物件

hitRenderer = hit.collider.GetComponent<Renderer>();
hitRenderer.material.color = Color.blue;

hit.collider 可以先理解成：「剛剛被射線碰到的那個 Collider」。課程接著從它身上取得 Renderer，再把材質顏色改成藍色。

射線命中
   ↓
hit 告訴我碰到誰
   ↓
取得對方 Renderer
   ↓
改成藍色

如果下一幀沒有再射中，而且之前確實有記住一個 hitRenderer：

else if (hitRenderer != null)
{
    hitRenderer.material.color = Color.red;
    hitRenderer = null;
}

五歲版：雷射照著它時變藍，雷射移開後把原本那個東西改回紅色，然後忘掉它。

命中後Raycast 只負責偵測；真正要變色、扣血、刪除，都是我們收到 hit 後自己寫的行為。
06

LayerMask：今天這支雷射只理指定 Layer

int layerMask = LayerMask.GetMask("NPC_Layer");

這行把名為 NPC_Layer 的 Layer 做成一個遮罩。課程原本沒有 LayerMask 的版本是：

Physics.Raycast(ray, out hit, distance)

加上 LayerMask 後則可以變成：

Physics.Raycast(ray, out hit, distance, layerMask)

ELI5：原本雷射說「路上誰都算」，現在改成「我今天只找掛著 NPC_Layer 名牌的人」。其他 Layer 就算在線上，也可以像透明的一樣不算命中。

LayerMask不是改變射線方向，而是決定「哪些物件值得被這次射線看見」。
07

整堂串起來：派探測線出去，把答案帶回來

1. 算世界方向
   TransformDirection(Vector3.forward)
          ↓
2. 建立 Ray
   position + direction
          ↓
3. Debug.DrawRay
   先讓自己看見射線方向
          ↓
4. 準備 RaycastHit hit
   等等裝命中答案
          ↓
5. Physics.Raycast(ray, out hit, distance)
          ↓
       有撞到嗎？
       ↙      ↘
    true      false
      ↓
 hit 告訴我撞到誰
      ↓
 改顏色 / 做其他事情
          ↓
6. LayerMask
   可限制哪些 Layer 才算命中
課程程式

範例裡 LayerMask 版本先被註解，先示範「全部都能命中」，之後再切換成指定 NPC_Layer 的版本，觀察其他 Layer 不再有反應。

這堂核心Ray 描述查詢方向；Physics.Raycast 執行查詢；RaycastHit 把命中結果帶回來；LayerMask 決定誰算數。
