ch3_17 Raycast_1（射線用法介紹）

先把 Raycast 想成一支「看不見的雷射筆」：從某個地方往某個方向照出去，再問 Unity「這條線有沒有碰到東西？」這堂先建立射線的基本零件，不急著背所有 overload。

RAYCAST · ORIGIN · DIRECTION · DISTANCE · LAYERMASK

拿一支看不見的雷射筆出去問路

射擊遊戲可以用它確認槍口前面是不是敵人；從空中往下射，也可以拿來判斷離地面還有多遠。用途很多，但骨架其實很固定。

01

Raycast：往一個方向射出看不見的線

課程先用槍戰遊戲當例子：槍口往前打一條無形射線，如果碰到可攻擊的怪物，就能知道目前瞄準的是誰，之後再做射擊、傷害或命中特效。

槍口 ●────────────────────→ 怪物
          看不見的射線

另一個例子是從空中往下射，測量角色離地面還有多遠，再拿這個結果決定何時打開降落傘。

槍戰：前面是不是敵人？
降落：下面離地面還多遠？
一句話記憶Raycast = 往某個方向問 Unity：「這條線碰到東西了嗎？」
02

Raycast 的常見零件：從哪裡、往哪裡、射多遠、哪些東西算數

課程提到 Raycast 有很多 overload，但常見參數一直圍繞幾件事：

Origin
→ 從哪裡開始射？

Direction
→ 往哪個方向射？

Max Distance
→ 最遠射多遠？

LayerMask
→ 哪些 Layer 才算目標？

可以把它畫成：

●────────────────────────→
↑                        ↑
Origin                   Max Distance

整條箭頭指的方向 = Direction

Direction 只回答「往哪裡」，不包含「多遠」。例如「往前」只是一個方向，真正最遠可以檢查多遠，要另外交給最大距離。

LayerMask 則像篩選器：場景裡就算有牆、地板、裝飾和敵人，你也可以只讓這次射線在意某些 Layer。

四個問題從哪射？往哪射？射多遠？哪些東西算？
03

Trigger 要不要算命中？Raycast 也可以決定

上一堂的 Trigger 像「可以穿過的感應區」。這堂課接著說，射線可以決定遇到 Trigger 時要怎麼處理：

Trigger 算命中
→ 雷射碰到感應區也算碰到

Trigger 不算
→ 把它當透明的，射線繼續往後

使用 Global 設定
→ 跟 Unity 專案裡的預設物理設定走

五歲版：前面有一扇透明感應門，你可以告訴雷射筆「看到透明門也要停」，或「假裝它不存在，繼續照後面的東西」。

Trigger 查詢Raycast 不只決定打哪裡，也能決定感應區要不要算碰到。
04

Ray：把「起點 + 方向」包在一起

課程最後特別介紹 Ray。這堂先把它理解成一個很簡單的小盒子，裡面主要放兩件事：

Ray
├─ origin      → 從哪裡開始
└─ direction   → 往哪裡前進

所以 Ray 本身不是「撞到了什麼」的結果，它只是先把一條射線的起點與方向描述好。

Ray = Origin + Direction
Ray一張小紙條：寫著「從這裡開始，往那邊射」。
05

不要背 overload，看到 Raycast 先問這五件事

1. 從哪裡射？       Origin
2. 往哪裡射？       Direction
3. 最遠射多遠？     Max Distance
4. 哪些東西才算？   LayerMask
5. Trigger 算不算？ Trigger 查詢設定

而如果程式先建立了一個 Ray：

Ray = Origin + Direction

就代表前兩個資訊先被包在一起了。這堂只先建立這個骨架，下一堂才繼續看實際射線程式怎麼寫。

這堂核心Raycast 是一條有起點、有方向、可限制距離與目標範圍的無形檢查線。
