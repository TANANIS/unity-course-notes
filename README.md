- 不保存逐字稿

- 標示舊版 Unity 內容與觀念校正
- 每堂課保留可驗證的完成檢查

## 本機預覽

直接開啟 `index.html`，或使用任意靜態伺服器。

## GitHub Pages

在 Repository Settings → Pages，將來源設定為 `Deploy from a branch`，Branch 選擇 `main`，資料夾選擇 `/ (root)`。

發布網址預期為：

`https://tananis.github.io/unity-course-notes/`
