ch1_1 開啟新專案

認識 Unity Hub 中建立、開啟與管理專案的基本流程。

核心操作

Projects
查看並開啟已存在於清單中的專案。
New
建立新的 Unity 專案。
Open
開啟未列在 Hub 清單中的既有專案資料夾。

建立流程

  1. 01選擇 New Project
  2. 02使用清楚一致的英文命名
  3. 03選擇固定、好找且會備份的路徑
  4. 04依需求選擇 2D 或 3D 範本
  5. 05建立專案
觀念校正

「C 槽容易損毀」並不精確。真正要控制的是系統重灌、容量不足、資料散落與沒有備份的風險。重點不是迷信磁碟代號，而是固定路徑、版本控制與備份。

一句話記憶 New Project → 命名 → 選路徑 → 選 2D／3D → Create

ch1_2 Unity 3D 環境介紹

認識 Unity 編輯器主要視窗、GameObject、Component，以及 Play Mode 的基本行為。

Scene編輯場景與擺放物件
Hierarchy管理場景物件與父子層級
Inspector查看元件並修改屬性
Game查看攝影機實際輸出
Project管理專案資源

核心概念

GameObject
場景中的物件容器。
Component
附加在 GameObject 上，賦予物件資料或功能。
Rigidbody
讓物件受 Unity 物理系統與重力影響。

播放控制

Play
執行遊戲。
Pause
暫停目前執行狀態。
Step
逐幀執行，觀察每一步變化。
Play Mode 警告

在 Play Mode 中修改 Inspector 數值，停止播放後通常會恢復原狀。播放中適合測試，不適合把正式設定只改在執行狀態裡。

一句話記憶 Hierarchy 選物件，Scene 編輯，Inspector 改屬性，Game 看結果，Project 管資源。

舊版課程提醒

MonoDevelop、UnityScript／JavaScript、舊版 Preferences、Build Settings、Asset Store 視窗與 Navigation 流程，現在不必照單全收。
